### 1. WEB-02：`error_report_url` 双重 `/api` → 三种导入的「下载错误报告」全 404（#63）

- 防复发：烟测新增 **W13**（真取 Blob + 断言 `PK` 魔数 + 断言 `toApiPath` 确实剥掉了 `/api`），`MIN_CASES` 12→13。

### 2. BE-07 烟测：造数子进程 `ModuleNotFoundError: No module named 'app'`

- 「造数脚本」写在临时目录，`sys.path[0]` 就是那个临时目录；**`sys.path.insert` 改不到子进程的 sys.path**，`cwd=backend` 也**没用**（Python 从不把 cwd 放进 sys.path）。
- 修法：子进程 env 显式 `"PYTHONPATH": str(BACKEND)`。修完 **56/56**。

### 3. 环境陷阱：沙箱 safe-delete 直接杀进程（**不是代码缺陷**）

- `PYTHONPATH` 被注入了 WorkBuddy 的 `sitecustomize.py`，它会 hook `unlink/remove/rmtree`，交给「批量删除守卫」。**本轮一旦已有一次拒绝记录（阈值 50 个文件）**，之后同轮所有删除一律拒绝，且拒绝方式是 **`raise SystemExit(1)`**。
- 症状极具迷惑性：spawn 出的 uvicorn **一行日志都不出**就没了；死在 `check_backup_dir` 的 `probe.unlink()`。`SystemExit` 继承 `BaseException`，应用里 `except OSError` 兜不住，也**不该**为它写 `except BaseException`。
- 解法：真机烟测一律 **`env -u PYTHONPATH <cmd>`**；**不要改烟测脚本去适配沙箱**（那是把环境问题烧进代码）。

### 4. 自造的两条红：孤儿进程占着 UDP 9527

  （`char`/`text_title`/`first_pos`/上下文）—— **字段零交集**。合并 = 「一个端点两种形状」，客户端得按 `subject` 分叉解析同一份 `items`。
- **数据来源 = 实时聚合 `recitation_events`**（`event_type='missed'`）。语文**没有**物化表（英语有 `word_mastery`，O(1)），
  且 **DDL 冻结** → 不新增表；代价（随该生背诵次数**线性增长**）在 §8.10 **如实标注**，不假装它和英语一样快。
- **两条口径线，都做反向验证**（撤掉必须转红）：
  ① **只回自己** —— 撤 `r.student_id = ?` → B 能看到 A 的漏字；
  ② **只算 `missed`** —— 「**还没背到**」不算漏（`engine.finish()` 刻意不补漏字事件，与 `settle.missed_detail` 是两回事）。
- 上下文由**服务端**从 `content_plain` 截（`CONTEXT_SPAN=4`）—— `content_plain` 是**纯汉字序列（无标点）**，
  客户端不该重写一遍取字逻辑；每页涉及的课文**一次取回**（`_content_plains`），不在循环里 N 次查询。
- 语文「重背这篇」**不新增接口**：`scope='lesson'` + `scope_detail.text_ids` —— 与配置页「选课文」**同一条路**。
  ⚠️ 语文**不给 `scope=wrong`**：背诵没有「只背这几个字」模式，按钮也写「重背这篇」而不是「只练错题」（不骗学生）。
- 前端新增 `wrong_char_book.dart`；`wrong_book_page.dart` 加**学科切换**；首页卡片改**两套文案两套数字**
  （英语「只练错题（N 个）」/ 语文「错题本（N 个字）」），`HomeData` **拆出独立 `wrongCharsCount`**（合成一个字段，切 Tab 数字会串）。
- 🐞 **顺带修掉一个潜伏缺陷（§八 #79）**：`WrongBookController.build()` 里**同步**调 `_load()`，
  而 `_load` 第一行读 `state` → Riverpod 抛「**Tried to read the state of an uninitialized provider**」，
  **错题本页上线以来从未真正渲染成功过**。老用例要么只测纯函数、要么固定 `pump` 从「我的」页**间接**进，**没有一条真渲染过**。
  已改 `Future.microtask`。→ **通用教训：页面级测试必须真把那一页渲染出来；Riverpod `build()` 里任何读 `state` 的调用都要推迟一帧。**

### 通用教训（已沉淀进 skill）
1. **「还有没做的吗」不能靠翻清单回答** —— 清单只列「已经知道要记的」。
   要**反向扫「声称」**（待上报/已上报/待补），再核对「声称」是否为真。**假声明是最坏的一类**。
2. **汇总表的数字要单独复算**：条号列表 vs 声明条数、各档之间有无重复归属。
   **总数对不代表分档对** —— 两处错误可以互相抵消。
3. **受保护文件的跨包改动，一律要有 §八 条目**；docstring 里写过不算。
