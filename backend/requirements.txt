# ⚠️ 依赖偏离说明（已上报）：
#   契约 §1 原写 `passlib[bcrypt]`，实测 passlib 1.7.4 与 bcrypt >= 4.1 **不兼容** ——
#   passlib 初始化时执行自检代码并传入超过 72 字节的密码，bcrypt 5.x 直接抛
#   `ValueError: password cannot be longer than 72 bytes`，CryptContext 无法初始化。
#   passlib 自 2020 年起停止维护。故改为**直接调用 bcrypt 原生 API**，
#   对外接口（hash_password / verify_password）保持不变，其他工作包无感知。
#   详见 backend/app/core/security.py 顶部注释。
