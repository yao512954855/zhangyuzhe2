# 背记系统 · Linux 运行说明（给第一次用的人）

整套系统就三步：**装一次 → 启动 → 浏览器用**。以后每天只要「启动」。

## 一、第一次使用（只需做一次）

把整个发布包文件夹拷到 Linux 机器上（U 盘 / scp 都行），进入文件夹，执行：

```bash
bash install.sh
```

装完会提示成功。如果报「找不到 python3」或「缺 python3-venv」，按屏幕提示先装
Python（需要 sudo 权限），再重跑一遍即可。**此步需要联网**（下载 Python 依赖，
走清华镜像）。

## 二、启动 / 停止

```bash
bash start.sh     # 启动（看到「启动成功」和网址即可）
bash stop.sh      # 停止
```

启动成功后，在同一局域网的任何电脑/手机浏览器打开：

- **管理端（老师用）**：`http://这台Linux的IP:8810/admin`
- **健康检查**：`http://127.0.0.1:8810/api/health`

查看这台机器的 IP：`hostname -I`（输出的第一段就是）。

学生端是手机 App：把发布包里的 **`学生端APP.apk`** 传到安卓手机上安装（微信/网盘/U 盘
都行），装好后打开 App，扫码或手输服务地址即可连接。

## 三、第一次登录

- 管理端账号密码写在 **`backend/.env`** 文件里（`ADMIN_INIT_USERNAME` /
  `ADMIN_INIT_PASSWORD`），发布包交付时会单独告诉你。
- **首次登录后请立即在「管理者管理」里改密码。**

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| start.sh 提示进程退出 | `tail -50 backend/logs/server.log` 看报错，把最后 50 行发给维护人 |
| 浏览器打不开管理端 | ①确认 `bash start.sh` 显示启动成功；②确认两台设备在同一局域网；③防火墙放行 8810 端口：`sudo ufw allow 8810`（Ubuntu） |
| 语音识别不可用 | 检查 `backend/asr.yaml` 是否存在（离线/未配置语音时其他功能不受影响） |
| 想换端口 | 改 `backend/.env` 里的 `APP_PORT`，`bash stop.sh && bash start.sh` 重启 |
| 数据在哪儿 | `backend/data/bjsys.db` 单文件。**备份 = 复制这个文件**（先 stop 再拷） |

## 五、日常维护速查

```bash
bash start.sh                        # 启动
bash stop.sh                         # 停止
tail -f backend/logs/server.log      # 实时看日志（Ctrl+C 退出）
cp backend/data/bjsys.db ~/bjsys-$(date +%m%d).db   # 备份数据库（先 stop）
```

> 声明：服务只监听局域网（0.0.0.0:8810），不要把 8810 端口暴露到公网。
