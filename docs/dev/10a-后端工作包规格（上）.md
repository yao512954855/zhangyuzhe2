## WP-BE-01 基础设施与契约骨架

### 目标

把《01-共享契约冻结》变成**能跑起来的骨架**：目录结构、数据库、鉴权、统一响应、日志全部就位。这个包做完，其他 16 个包就能并行开工。

| F19 | 健康检查 | `GET /api/health`（免鉴权）：返回服务版本、DB 可达、迁移版本号、ASR 配置是否就绪 |

### 关键实现要点

- **写锁必须用进程级 `threading.Lock`**，不是数据库锁——SQLite 的 `busy_timeout` 只是兜底，高并发下仍会 `database is locked`。
- 迁移脚本**不允许包含业务数据**，只允许结构 + settings 种子值。
- `get_current_user` 必须查库确认用户 `status='active'`，不能只信 JWT（停用账号的旧 token 要立即失效）。
- 时间统一用 `datetime.now(timezone.utc).strftime('%Y-%m-%dT%H:%M:%SZ')`，不要用 `datetime.utcnow()`（已废弃且无时区）。

### 功能点详述

| # | 接口 | 要求 |
|---|---|---|
| F1 | `POST /api/auth/login` | 支持学号或用户名；bcrypt 校验；失败统一 `20002`（**不区分「用户不存在」与「密码错误」**，防枚举）；停用账号 `20003`；成功后更新 `last_login_at`；返回 JWT + 用户信息 |
| F2 | `POST /api/auth/register` | 学生自主注册；`role='student'`、`register_source='self'`；**可不选班级**（进「未分班」）；学号已存在 → `20001`，提示「请直接登录」，**绝不覆盖原账号**（需求 §3.1）；注册即可用，无需审核 |
| F3 | `GET /api/auth/me` | 返回当前登录用户基本字段 |
| F4 | `GET /api/classes` | 分页；支持 `grade`/`semester`/`status`/`keyword`；返回 `student_count`、`unassigned_count` |
| F5 | `POST /api/classes` | 创建班级；同名校验（活跃班级内唯一，靠 `uk_classes_name` 部分索引）；重复返回 `10001` 带明确提示 |
| F6 | `GET /api/students` | 分页；支持 `class_id`（含 `null` 查未分班）/`status`/`register_source`/`keyword`；附带 `practice_count`、`accuracy`（**正确率口径必须走契约 §8.1**） |
| F7 | `POST /api/students/import` | 两步式第一步：解析 xlsx → 校验（学号非空/姓名非空/班级存在性）→ 返回 `preview_token` + `summary`（含 `duplicated`）+ `invalid_rows` + 错误报告地址；**不落库** |
| F8 | `POST /api/students/import/commit` | 凭 token 入库；**同一学号重复导入为更新而非新增**（需求 §4.4）；未填密码用 `default_password`；同一事务提交；返回 `created`/`updated` |
| F9 | `POST /api/students/{id}/assign-class` | 单个归班；`class_id=null` 表示移出班级 |
| F10 | `POST /api/students/batch-assign-class` | 批量归班；返回成功/失败条数明细 |
| F11 | `POST /api/students/{id}/reset-password` | 重置密码；写审计日志 |
| F12 | `PATCH /api/students/{id}` | 改 `real_name`/`status`/`class_id`；`status='disabled'` 后该生所有 token 立即失效（BE-01 的 `get_current_user` 查库保证） |
| F13 | `GET /api/me/profile` | 返回本信息 + `preferred_grade`/`preferred_semester` + 护眼设置 |
| F14 | `PUT /api/me/profile` | 更新年级学期偏好（**双向持久化**：本地为主、服务端同步，需求 §5.2） |
| F15 | 审计 | 导入、归班、重置密码、停用全部写 `audit_logs` |

### 关键实现要点

- 所有涉及 `username` 的查询/写入注意 `COLLATE NOCASE`（`20260001` 与 `a20260001` 不冲突，但 `Abc` 与 `abc` 视为同一）。
- 导入解析要容忍：学号被 Excel 存成数字（`20260001.0` → 去掉 `.0`）、首尾空格、全角数字。
- 学生导入**班级列**可写班级名（而非 ID），按「年级+学期+名称」匹配；找不到则报错行，不自动建班（**与内容导入的 `create_missing_units` 策略不同，班级不自动创建**）。
- 密码策略：注册用户名 4–20 位字母数字（全校唯一）、`real_name` 1–20 字、密码 6–20 位且**允许纯数字弱口令**（小学生场景，需求已明确）；bcrypt rounds 用默认 12。
- 登录的账号锁定计数放内存（BE-01 可提供 `rate_limit` 的计数能力），**不落库**——锁定期短，重启丢失可接受。
- 归班后若该生已有 `preferred_grade` 为空，可顺带按班级年级回填（**建议做，减少学生首次选择成本**）。

### 关键实现要点（本包最容易出 bug 的地方）

**A. `content_plain` 与 `content_pinyin` 严格等长（硬约束）**

- `content_plain`：从背诵范围正文中提取**纯汉字序列**——去标点、去空白、**去数字与英文字母**，每个汉字之间不留空格。
- `content_pinyin`：对 `content_plain` 的每个汉字取无声调拼音，**空格分隔**。
- 两者按空格切分后数组长度必须一致，不一致直接拒绝入库（`pinyin_check='mismatch'`）。
- 多音字处理：`pypinyin` 默认取常用音，可接受；**不要**用 `heteronym=True` 导致同字多音膨胀。

**B. 段落切分规则**

- 以 Excel 单元格内换行为界切分；空行忽略。
- `chars` 只统计汉字（与 `content_plain` 口径一致），不含标点。
- `recite` 默认 true，前端可取消勾选。
- 段落内标点保留在 `paragraphs[].text`（用于展示），但**不进 `content_plain`**。

**C. 词条导入的 upsert 语义**

- 判定「重复」的键是 `(unit_id, en)`（对应 `uk_words`）。
- `overwrite`：更新 `cn`/`accepted`/`phonetic`/`pos`/`example_*`/`type`/`require_spell`/`order_no`；**`status` 不覆盖**（避免把已停用的词条意外启用）。
- `skip`：完全跳过，计入 `skipped`。
- **绝不物理删除已有内容**（避免破坏历史记录引用）。

**D. 停用内容不参与出题**

- 所有「给练习用」的查询（`only` 筛选、组卷）必须带 `status='active'`。
- 管理端列表默认查全部（含停用），带 `status` 参数。

**E. 删除保护的两个层级**

- 词条级：看 `answers` 有无引用该 `word_id`。
- 单元级：看单元下所有词条与课文，任一有记录即拒绝。
- 统计用 `EXISTS` 子查询，不用 `COUNT(*)` 全表扫。

**F. Excel 解析容错**

- 表头行按**列名匹配**而非固定列序（用户可能调换列顺序）。
- 字符串 trim；全角转半角（数字、字母、括号）。
- 类型列支持「单词/短语/句子」与英文 `word/phrase/sentence` 两种写法。
- 单文件上限 10MB（`40004`），超行数（建议 5000 行）给出明确提示。

**判分引擎（对外签名见契约 §7.1，必须严格遵守）**

| F1 | 归一化 | 按需求 §6.1：转小写、去首尾空格、连续空格合一、去英文标点（**保留撇号**）、中文去标点空格、数字转阿拉伯数字 |

### 关键实现要点

- **判定必须在服务端**，`expected` 在响应中判定后才出现——这是防作弊的核心设计，客户端不得提前拿到。
- `judge_spell` 的 `diff` 是**逐位**对齐结果，长度取 `max(len(expected), len(actual))`；`extra` 位 `expected=None`，`missing` 位 `actual=None`。
- 编辑距离用标准 DP + 回溯；目标序列与识别序列都先归一化，避免大小写导致假差异。
- `SequenceMatcher` 对短词（≤4 字符）区分度差，长度 <5 的**不走 fuzzy**（需求已明确规定 ≥5）。
- `word_mastery` 更新必须是「读-改-写」在同一事务内，且走 `write_tx`（并发安全）。
- `mastery_streak` 从 settings 读（默认 3）；答错时 `streak` 立即归零、`mastered_at` 置 `NULL`。
- 组卷的 `random_n` 用 `random.sample`；`wrong_first` 需 join `word_mastery` 按 `wrong_count` 排序。
- `scope='unmastered'` 排除 `mastered_at IS NOT NULL` 的词条。
