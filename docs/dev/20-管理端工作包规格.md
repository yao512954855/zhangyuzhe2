# 背记系统 管理端工作包规格 — WP-WEB-01 ~ 03

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 适用端 | 管理端 Web（`admin-web/`），Vue 3 + Vite + TypeScript + Element Plus + Pinia |
| 前置必读 | **《01-共享契约冻结》全文**（尤其 §5 HTTP 契约、§12.1 前端规范） |
| 需求追溯 | 需求说明书 §4 内容管理端需求（全章） |

> **管理端 = 管理者端**。全文不使用「老师」字样（需求 §1.3 术语约定）。管理端不做护眼主题——那是学生端的硬需求；管理端追求信息密度与操作效率。

## WP-WEB-01 管理端外壳与登录

| 项 | 内容 |
|---|---|
| 优先级 | **P0** |
| 直接依赖 | WP-BE-01（接口契约已冻结即可开工） |
| 被依赖 | WEB-02、WEB-03 |
| 需求追溯 | §4.1 登录 |

### 目标

搭出管理端的骨架：能登录、有导航、有统一请求层、有统一错误处理。做完这个包，WEB-02/03 可以并行开工。

### 功能点详述

| # | 功能 | 要求 |
|---|---|---|
| F1 | 工程脚手架 | Vite + Vue3 + TS；`package.json` **锁定版本**；开发代理指向 `http://localhost:8810` |
| F2 | 统一请求层 `client.ts` | 自动带 `Authorization`；统一解包 `{code,message,data,trace_id}`；`code!=0` 抛 `BizError`（含 code/message/trace_id）；**统一在此弹错误提示，页面不重复弹**；401 清 token 跳登录 |
| F3 | 路由聚合 | `router/index.ts` 用 `import.meta.glob('./routes/*.ts', { eager: true })` 聚合；**WEB-02/03 各自新增 routes 文件，谁都不改 index.ts** |
| F4 | 登录页 | 用户名 + 密码；调 `POST /api/auth/login`（**`role` 固定传 `admin`**）；成功后存 token 到 localStorage + Pinia；错误提示含 `trace_id` |
| F5 | 路由守卫 | 无 token → 跳登录；已登录访问登录页 → 跳工作台 |
| F6 | 主布局 | 左侧菜单 + 顶部栏（用户名/退出）；菜单项由路由元信息 `meta.title` 生成；支持折叠 |
| F7 | 工作台首页 | 展示欢迎信息 + **服务地址与二维码卡片**（内容由 WEB-03 实现，本包只留挂载点占位组件） |
| F8 | 通用组件 | `PageHeader`（标题+操作区）、`EmptyState`（空状态）、`LoadingBox`（骨架/加载） |
| F9 | 格式化工具 | 时间 `ISO UTC → 本地 YYYY-MM-DD HH:mm`；百分比两位小数；时长 `ms → 分秒` |
| F10 | 响应式 | 最小适配 1280×720；表格在窄屏可横向滚动 |

### 验收用例

| # | 用例 | 预期 |
|---|---|---|
| U1 | `npm run dev` 启动 | 无报错，登录页可访问 |
| U2 | 正确账号登录 | 进入工作台；localStorage 有 token |
| U3 | 错误密码登录 | 提示错误并附 `trace_id`；停留登录页 |
| U4 | 直接用学生账号登录 | 被拒（`role` 不符返回 `20002`） |
| U5 | 未登录直接访问 `/students` | 重定向到登录页 |
| U6 | 任意接口返回非零 `code` | **只弹一次**错误提示（不重复） |
| U7 | token 过期后调接口 | 自动清 token 并跳登录页 |
| U8 | 新增一个 `routes/xxx.ts` 文件 | 菜单与路由自动出现，**未改 index.ts** |
| U9 | 刷新页面 | 登录态保持（token 持久化） |

## WP-WEB-02 内容管理与导入向导

| 项 | 内容 |

### 目标

管理者用 Excel 把教材内容导进来，能预览、能修、能停用、能安全删除。


### 功能点详述

| # | 页面/功能 | 要求 |
|---|---|---|
| F1 | 单元列表 | 筛选（学科/年级/学期/状态）+ 分页；列显示词条数/课文数/启用数；操作：新建、编辑、停用/启用、删除 |
| F2 | 单元新建/编辑 | 表单校验：学科/年级(1–9)/学期/名称必填；重名前端先提示，后端 `10001` 兜底 |
| F3 | 单元删除 | 后端返回 `30003` 时，弹窗明确说明「该单元已有练习记录，为保证统计完整只能停用」并给「改为停用」按钮（**不要只弹一个红字报错**） |
| F4 | 单元详情 | 两个 Tab：词条 / 课文；均支持分页与分页大小切换 |
| F5 | 词条表格 | 列：序号/类型/英文/中文/可接受答案/音标/是否拼读/状态；支持批量勾选 |
| F6 | 批量启停 | 选中后批量启用/停用；显示成功条数 |
| F7 | 词条编辑 | 弹窗表单；保存时若后端返回 `history_affected=true`，**二次确认**：「该词条已有练习记录，修改不影响历史成绩，确认？」 |
| F8 | 词条删除 | 后端 `30003` 时提示记录数并建议停用 |
| F9 | 课文表格 | 列：标题/作者/总字数/背诵字数/段落数/状态 |
| F10 | 导入向导（4 步） | ① 选类型（英语词条 / 语文课文）并下载模板 → ② 上传文件并校验 → ③ 预览与修正 → ④ 确认入库并看结果；**步骤条常驻可见** |
| F11 | 步骤 2 上传 | 拖拽或点击上传；显示解析进度；校验失败列出 `invalid_rows`（行号 + 原因 + 原始数据），可下载错误报告 |
| F12 | 步骤 3 词条预览 | 展示有效行表格 + 汇总（总/有效/无效）；列出将新建的单元 `new_units` 并**要求用户确认是否自动创建**；提供 `on_duplicate`（覆盖/跳过）单选 |
| F13 | 步骤 3 课文预览 | **段落列表渲染，每段一个复选框**（默认按模板勾选），用户可调整背诵范围；显示每段字数与总字数；提交时回传调整后的 `recite_scope` |
| F14 | 步骤 4 结果 | 显示 `created`/`updated`/`skipped`；提供「继续导入」与「查看内容」入口 |
| F15 | 错误处理 | 模板列缺失（`40002`）时引导下载最新模板；文件过大（`40004`）提示拆分；非 xlsx（`40001`）提示格式 |
| F16 | 导入后可见性 | 入库成功后跳转单元详情，能立即看到新内容 |

### 关键交互要求（这几条直接影响可用性）

- **课文预览必须让用户勾选背诵范围**，不能靠用户在 Excel 里算段落号——这是需求 §4.5 明确的（接口 §6.4 说明段）。
- 导入向导的状态要能在浏览器刷新后恢复（用 sessionStorage 存 `preview_token` 与步骤），避免误刷新要重传文件。
- 大批量导入（>500 行）预览表格要虚拟滚动或分页，不能一次渲染 5000 行卡死。
- 停用/删除操作一律**二次确认**，确认文案要说清后果（停用=不再出题但保留记录；删除=彻底移除）。

### 验收用例

| # | 用例 | 预期 |
|---|---|---|
| U1 | 新建单元 | 列表出现新单元；重名给出明确提示 |
| U2 | 筛选 三年级+上学期+英语 | 结果正确 |
| U3 | 删除含练习记录的单元 | 弹窗说明原因并提供「改为停用」 |
| U4 | 改为停用后 | 单元状态变 `inactive`，学生端不再出现 |
| U5 | 下载 templates/words | 打开可见 14 列且带下拉 |
| U6 | 上传含 2 行错误的词条文件 | 列出错误行与原因；可下载错误报告 |
| U7 | 预览页确认「自动创建单元」并入库 | 新单元与词条出现，结果页 `created` 正确 |
| U8 | 上传课文并进入预览 | 段落列表渲染，复选框默认按模板；调整后提交，库中 `recite_scope` 为调整后的值 |
| U9 | 编辑已有练习记录的词条 | 保存时出现二次确认；确认后保存成功 |
| U10 | 刷新导入向导页面 | 能恢复到当前步骤与 `preview_token`，无需重新上传 |
| U11 | 导入 600 行文件 | 预览表格不卡顿（虚拟滚动/分页） |
| U12 | 上传非 xlsx | 提示格式错误，不进入预览 |
| U13 | 上传缺列文件 | 提示下载最新模板 |

### 功能点详述

| # | 页面/功能 | 要求 |
|---|---|---|
| F1 | 班级管理 | 列表（含学生数/未分班数）+ 新建；筛选年级/学期/状态 |
| F2 | 学生管理 | 列表：学号/姓名/班级/来源/状态/最后登录/练习数/正确率；筛选班级（含「未分班」）、状态、来源、关键词 |
| F3 | 学生导入向导 | 两步：上传校验 → 预览（错误行 + 重复行）→ 确认入库；可设 `default_password`；结果页提供账号密码对照表下载入口 |
| F4 | 归班操作 | 单个归班（行内下拉）与批量归班（勾选后选班级）；归班后可筛选「未分班」验证 |
| F5 | 重置密码 | 弹窗输入新密码；成功后提示需告知学生 |
| F6 | 学生停用 | 二次确认，提示「停用后该学生无法登录」 |
| F7 | 班级概览 | 卡片区（人数/今日活跃/完成率/平均正确率/平均用时）+ 趋势折线图 + 错题 Top 榜；日期范围选择默认近 7 天 |
| F8 | 单元掌握度 | 正确率、已掌握比例、未完成学生列表、难词榜（正确率升序，低于 60% 标红）。⚠️ **口径（2026-09-25 裁决 A，§八 #82）**：「未完成学生」= **练过该单元但未完成**的学生 —— **学生宇宙 = 练过该单元的人**（`COUNT(DISTINCT answers.student_id)`），**从未练过的学生不在其中** |
| F9 | 学生报告 | 概要卡片 + 最近场次表 + 背诵记录表 + 错词表；可切换学生 |
| F10 | 申诉复核 | 列表（默认 `pending`）+ 详情（题目、标准答案、识别文本、匹配类型）+ 复核操作（成立/驳回 + 备注）；**页面需明确说明「复核不改判分，仅作质量数据」** |
| F11 | 服务地址页 | 展示所有网卡地址、推荐地址高亮、当前 URL、**大尺寸二维码**（由 `qr_content` 渲染）；附「App 扫码即可连接」说明与 IP 变化提示 |
| F12 | 工作台复用 | `ServerQRCard` 组件同时用于工作台首页与服务地址页 |
| F13 | 图表 | 用 ECharts；趋势图、正确率分布用中文标签；数字带单位/百分比 |
| F14 | 空状态与引导 | 无班级/无学生/无数据时显示引导性空状态与主操作按钮，不要空白页 |

### 关键交互要求

- **二维码要足够大且高对比**（建议 ≥240×240），并附文字版地址，二维码识别失败时能手动输入。
- 学生导入的错误提示要具体到行（「第 7 行：学号重复（已存在 userId=1024）」）。
- 数据看板的数字要标注口径（正确率已排除识别为空；班级概览按词条维度算完成率）。
- 「未分班」必须是一个显式筛选项，而不是一个隐藏状态——学生自主注册后很容易落到这里。

## 管理端共通约束（三个包都要遵守）

| # | 约束 |
|---|---|
| 1 | 所有请求走 `api/client.ts`，**不得在页面里直接 `axios`/`fetch`** |
| 2 | 分页参数统一 `page`/`page_size`，默认 20，可选 50/100 |
| 3 | 时间展示统一用 `utils/format.ts`，按本地时区 |
| 4 | 危险操作（删除/停用/重置密码）必须二次确认，文案说清后果 |
| 5 | 表格空数据、加载中、错误三态齐全 |
| 6 | 表单校验前端先做一遍，后端 `10001` 兜底并展示具体字段 |
| 7 | 不使用「老师」等术语，统一「管理者」「学生」 |
| 8 | 路由与 API 封装按包分文件，不修改他人文件 |
