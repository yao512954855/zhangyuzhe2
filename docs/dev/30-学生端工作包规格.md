### 关键实现要点（踩坑集中区）

- **`http://` 只对原生 App 有效**：本端是原生 App（非浏览器套壳），所以能用局域网 http，**这是选用 Flutter 的原生优势，不要退回 WebView**。
- Android 9+ 默认禁止明文 HTTP：需在 `AndroidManifest.xml` 的 `<application>` 上加 `android:usesCleartextTraffic="true"`（局域网场景必须）。
- 录音权限被拒后**不能反复弹窗**，给一次清楚的说明 + 跳设置的按钮即可。
- UDP 广播在部分安卓版本/路由器下会被拦（AP 隔离），所以广播只是**增强**，扫码是**主路径**。
- 主题切换要**立即生效且不闪白**——切换时避免整树重建导致的闪烁（这是护眼硬要求中的"禁止闪烁"）。
- 分龄字号需要在运行时根据所选年级动态计算，不能写死一套。

### 功能点详述

| # | 功能 | 要求 |
|---|---|---|
| F1 | 题目展示 | 模式一显示中文释义（有例句则第二屏可显示，可关闭）；模式二显示英文；**不显示答案**；`target_len` 用于渲染占位框 |
| F2 | 两步流程 | 模式一：先说单词（`task_type=word`）→ 成功后进入拼读（`task_type=spell`）；模式二：直接说中文（`task_type=zh_answer`），**不拼读** |
| F3 | 拼读引导 | 屏幕按**逐字母固定切分**显示引导（如 `c｜l｜a｜s｜s`）；短语/句子按单词分组（需求 §5.4）。**严禁音节切分**（`cla-ss`、`pen-cil`）——实测 ASR 无法识别非词字母组合，22 条样本无一正确（`qa/ASR预研报告.md` §3.1） |
| F4 | 录音动效 | **明显的波形或呼吸圆**，让学生知道在听（UI 规范 §5.2）；判定超 1 秒显示 loading |
| F5 | 逐字母回显 | UI 规范 P7；按服务端 `diff` 渲染：`match` 正常 / `wrong` 高亮差异位 / `missing` 占位框 / `extra` 标记多余；**同时展示学生原始识别文本**（如「see ell aye ess ess」） |
| F6 | 回显停留 | **不自动消失**，由学生点「继续」翻页（需求 §5.4 明确要求） |
| F7 | 重试（**语音优先**） | 单步骤最多重试 2 次；**第 3 次失败才自动弹出键盘输入**。前 2 次失败只提示「没听清，再说一次」，**不得引导键盘**。降级后 `used_keyboard=1` 必须上报 |
| F8 | 键盘兜底（**降级路径，非主路径**） | 「改用键盘」入口常驻但**视觉弱化**（不做主按钮），不做二级菜单（需求 §5.4）；**默认不主动引导**，仅在语音不可用或连续失败时才高亮提示；键盘模式提交走 `POST /api/sessions/{id}/answers` |
| F9 | 判分展示 | 正确/错误用**内联反馈**（颜色 + 图标 + 文案），**不弹模态框**（UI 规范 §5.2） |
| F10 | 识别为空 | 提示「没听清，请靠近麦克风再说一次」，**不计错**，可重录（`error.code=50003`） |
| F11 | 申诉入口 | `can_appeal=true` 时显示「我读对了」按钮 → 调 `POST /api/answers/{id}/appeal`；点后不改变当前对错显示，但记一次申诉 |
| F12 | 提示机制 | 卡壳时（静音 8 秒或主动点）给三档提示：一档显示占位框数量、二档给首字母、三档给完整答案；每次提示影响得分 |
| F13 | 计时 | 按 §5.8：题目渲染完成开始计时；同时记 `duration_ms` 与 `first_voice_ms`；限时到点按 `settings.time_limit_behavior` 处理（A 判错/B 跳过/C 标记） |
| F14 | 限时展示 | 顶部倒计时徽标；剩余 10 秒变警示色（**不用闪烁**，用颜色与数字变化） |
| F15 | 提交 | 每次判定完成后调 `POST /api/sessions/{id}/answers` 落库；`Idempotency-Key` 防重复 |
| F16 | 结算页 | UI 规范 P9：正确率、题量、用时、提示次数、错题列表（含你的答案 vs 正确答案） |
| F17 | 断网降级 | WebSocket 失败 → 当前题切键盘输入，**不阻塞整个练习**（契约 §6.5） |
| F18 | 混合模式 | `mode=mixed` 时每题随机为中→英或英→中，题目上要有模式标识让学生明白要做什么 |

## WP-APP-04 语文背诵页

### 功能点详述

| # | 功能 | 要求 |
|---|---|---|
| F1 | 进入状态 | 进入课文后**屏幕不显示正文**，只显示标题与「开始背诵」按钮（需求 §5.6 流程）；避免学生直接照着念 |
| F2 | 逐字点亮 | 按服务端下发的进度渲染：已背出的字正常显示；当前位置留**空框**；未背到的字**完全不显示**（仅保留占位空间）（需求 §5.6） |
| F3 | 按字推进 | **显示粒度按字**（已定稿，需求 §5.6）；「父亲」拆成「父」「亲」分别点亮 |

| F6 | 三档提示 | 一档：后面还有几个字（一排空框）；二档：下一个字首字；三档：下一个字完整答案（需求 §5.7） |
| F7 | 提示触发 | 「我卡住了」按钮（每次降一档）+ 静音 8 秒自动降档；同位置不重复触发；界面显示当前已用提示次数 |
| F8 | 暂停/继续 | 提供「暂停」按钮；暂停明确停止录音与计时 |
| F9 | 重新开始 | 提供「重新开始本段」；确认后重置进度，`restart_count+1` |
| F10 | 识别失败反馈 | 连续识别失败给明确提示（如「没听清，请靠近麦克风再说一次」），**不能静默卡死**（需求 §5.6） |

| F12 | 结束 | 「结束背诵」按钮 → `POST /api/recitations/{id}/settle`（服务端重算，客户端数据仅参考） |
| F13 | 结算页 | 总字数、已背字数、漏字数、提示次数（分档）、总用时、首次发声延迟、评级（优秀/良好/合格/待加强） |
| F14 | 回看 | 结算页列出漏掉和背错的字及其位置（需求 §5.6） |
| F15 | 事件上报 | 提示/漏字/重开等事件按需上报（`POST /api/recitations/{id}/events`），断线可补报 |
| F16 | 文本布局可读性 | 课文显示用大字号（按分龄档位）+ 适中行距；**已背出的字与当前位置要用色彩区分**，不能只靠亮度差异（暗色主题下尤其要注意） |
