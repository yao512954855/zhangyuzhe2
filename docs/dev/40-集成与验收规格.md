### 4.0 第一批结论摘要（语种与优化手段，TTS 标准音，**只能当上限看**）

| 指标 | 实测 | 门限 | 判定 |
|---|---|---|---|
| 拼读准确率（**`zh`**） | **95.0%** | ≥85% | ✅ 达标 |
| 拼读准确率（`en`） | 85.0% | ≥85% | ⚠️ 压线 |
| 整词准确率 | 85.7% | ≥95% | ❌ 未达 |
| 空结果率 | 0% | ≤5% | ✅ |
| 结果稳定性（同音频 ×3） | 100% 一致 | — | ✅ |
| ASR 延迟 P95 | 626 ms | ≤1.5s | ✅ |

**由此产生的 5 项设计变更**（已回写需求 §5.4/§6.2/§9.1/§9.2/§9.3/§9.7 与契约 §6.3/§9.2）：

| # | 变更 | 依据 |
|---|---|---|
| 1 | 拼读语种 `en` → **`zh`** | 实测 +10 个百分点；`en` 会把字母串拼成单词 |
| 2 | **定制热词作废** | `vocabulary`/`context` 两种参数均无改善 |
| 3 | 切分引导改**逐字母**，**禁用音节切分** | 音节切分 22 条样本无一正确 |
| 4 | **多模态仲裁一期启用** | 与 ASR 互补（4 条判断不一致，omni 补对 3 条） |
| 5 | 谐音表扩容优先级 `R` > `B/P` > `W/V` > 元音 | 实测混淆方向 |

### 4.1 目的

用**真实音频**回答三个问题：

1. 云 ASR 对**孤立字母**（`c`、`l`、`s`、`b`、`d`、`e`…）的实际识别率是多少？
2. 孩子念「单词 + 拼读」时，整词识别与字母序列识别分别有多准？
3. 谐音表需要覆盖到什么规模，判分阈值定在多少才合理？

### 4.2 方法

| 步骤 | 内容 |
|---|---|
| 样本 | 挑 **20 个高频单词**（长度 3–10，含 `class`、`restaurant`、`beautiful` 等），覆盖不同难度 |
| 录音 | 至少 3 名儿童（或成人模仿儿童口音），每个词录「整词」与「逐字母拼读」各一遍；中英混合也录 |
| 工具 | 直接用 `AliyunProvider` + 一段离线脚本，把音频喂进去，导出识别文本 |
| 指标 | 整词识别准确率、字母序列准确率、空结果率、平均延迟 |
| 输出 | `qa/ASR预研报告.md`：原始数据表 + 结论 + **对 §6.2 判分规则的修订建议** |

### 4.3 第三批（真人录音）的判定去向

> **前提约束（姚工已定，不可违背）**：本产品核心是语音交互，**语音优先级必须高于键盘**。任何结论都不允许把拼读改成「键盘为主、语音可选」。识别率不达标的解法是**加强语音链路**（扩谐音表、多模态仲裁、切分引导），**不是退回键盘**。

| 真人录音的字母识别率 | 则… |
|---|---|
| ≥ 85% | 按现设计（`zh` + 多模态仲裁）执行，微调相似度阈值与谐音表 |
| 50% – 85% | **扩谐音表 + 放宽 `fuzzy` 条件 + 强化逐字母切分引导**；键盘降级阈值提前到第 2 次失败（**仍属降级，非主路径**）；**确认多模态仲裁已启用** |
| < 50% | **多模态仲裁升级为主判据之一**（不再只是兜底）+ 扩谐音表 + 强化切分引导；**不得改为键盘为主** |

> 要**正视**数据，不要因为已经写了文档就硬撑；但退路是「把语音判准」，不是键盘。对应需求 §9.7 / §9.8。

### 4.4 第一批已锁定的三条口径（第二批不得推翻，除非给出实测反证）

1. **拼读语种用 `zh`** —— 但该结论测于旧模型 `qwen3-asr-flash`，**必须先在 `fun-asr-flash` 上复验**；
   若真人录音或新模型显示 `en` 更优，须在报告中给出证据并同步修订需求 §9.2。
2. **不使用热词** —— 除非换厂商/换模型，且重新实测证明有效。
3. **保持"忠实优先"** —— 判分模型**不得**是会把错读纠正成正确词的模型（`qwen3-asr-flash` 已禁）。
   仲裁后端（多模态 `qwen3.5-omni-plus` 或第二个 ASR `qwen-audio-3.0-asr-flash`）保持启用，
   它是「加强语音链路」的手段，与语音优先原则一致。

这套拆分方式的核心是**先冻结契约再并行**：17 个包里只有 BE-01 是真正的串行阻塞点，剩下 16 个理论上都能同时开工——前提是每个 Agent 都严格只碰自己清单里的文件、只调契约里定义的接口。
