### 2.2 复用既有表（不新建）

- **正确率趋势**（WP-2A）：聚合 `answers` / `sessions`，**不建物化表**（同语文错题本口径）。

新表一律 `ON DELETE CASCADE` 跟随 `users` / `classes`，避免孤儿行。
⚠️ 注意：`users` 物理删除会 CASCADE 掉全部记录 —— 与契约 §14.1 第 2 项（学生删除走软停用）口径一致。

### 3.1 英语 hint 端点的**防作弊门控**（WP-2J，重点）

⛔ **不动契约 §9.1「组卷响应绝不返回答案」**（§13.4 红线原样保留）。hint 走**独立请求**：

| 档 | 下发内容 | 门控条件 |
|---|---|---|
| 1 | 占位框数量（来自 `target_len`） | 立即（**一期已有**） |
| 2 | 首字母 | **本题失败 ≥ 1 次** |
| 3 | 完整答案 | **本题失败 ≥ 2 次**（即第 3 次尝试前） |

- 每次提示计 `used_hint_level`，随答案上报并影响得分（与语文一致）。
- 越档请求 → `70006`；无 hint 的题型（英→中）→ `70007`。

## 4. 新增错误码（70000 段：二期学习类）

> ⚠️ **不能再用 40000 段** —— 该段已被「导入」占用（`FILE_FORMAT_INVALID=40001` 起）。

# 70000 段：二期学习能力（新增）
PLAN_NOT_FOUND       = 70001
HOMEWORK_NOT_FOUND   = 70002
HOMEWORK_EXPIRED     = 70003
SRS_PLAN_NOT_FOUND   = 70004
VERSION_NOT_FOUND    = 70005
HINT_EXHAUSTED       = 70006  # 提示档位用尽

> 越权与「不存在」**同码复用**（`10004` 或对应 4000x）—— 不暴露资源存在性（沿用 A3 的安全口径）。

### 7.1 三个「不能并行」的硬点

1. **迁移脚本 `002_wave2.sql` 只有一个文件** —— 批次 0 由主 Agent 一次写完，子包**不得各自加表**。
2. **公共请求层**：`admin-web/src/api/client.ts`、`student-app/lib/core/net/api_client.dart` —— 若某包需新「通道能力」，
   **停下来报告 → 统一改 → 通知受影响包**（契约 §13.6 / §八 #62/#65 的教训）。
3. **烟测不能并行** —— 抢 UDP `9527` 与 `8810/8812/889x/8817+5285/8818+5286`。集成期一律串行。

### 7.2 无冲突的部分（放心并行）

- 后端路由：`api/*.py` 定义 `router`，`main.py` **自动发现**，无需注册行（契约 §13.6）。

- 学生端路由：各包用 APP-01 占位文件接入，**不新建同名页**。
