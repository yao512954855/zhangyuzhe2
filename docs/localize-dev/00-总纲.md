## 一、背景与目标

背记系统（S2 简化版）目前有三处**云端依赖**，断外网即失效、长期使用有成本：

| 能力 | 云端实现 | 代码位置 |
|---|---|---|
| TTS 听写播报 | 百炼 qwen3-tts-flash（HTTP） | `backend/app/services/tts_service.py` |
| OCR 拍照批改 | 阿里云读光 RecognizeHandwriting（SDK） | `backend/app/services/dictation_service.py`（`_OcrClient`） |
| ASR 语音识别 | 百炼（流式 WS + 批量 HTTP，provider 抽象） | `backend/app/services/asr/`（aliyun_provider 等） |

目标：**新增本地引擎通道，做成「三模式」可配置**，接口契约与客户端行为完全不变：

```
local   ：只用本地引擎（断外网全功能可用）
hybrid  ：本地优先，失败自动回退云端（默认，管理端叫「智能切换」）
cloud   ：只用云端（与现状行为一致）
```

甲方给的参考技术栈中两处已纠错（**不要照抄**）：
- 「Vosk + ML Kit 做 OCR」错误 —— Vosk 是语音识别不是 OCR，本项目 OCR 用 RapidOCR；
- 「GRMR-V3-L1B 短句语法评价」—— 简化版无语法评价功能，**不引入**。

## 二、范围

**做**：三模式配置体系、TTS 本地（Piper 模型）、OCR 本地（RapidOCR）、ASR 本地（Vosk + sherpa-onnx）、管理端模式切换页、模型下载脚本、Linux 部署适配。

**不做（明确出范围）**：
- App（student-app）**一行不改**——所有变化在后端内部路由；
- 不改 `/api/tts`、`/api/dictation/grade`、WS 协议的任何请求/响应结构；
- 不动 001~003 迁移文件（DDL 冻结）；新增种子值走 `004_capability.sql`；
- 不做每能力独立三档的**管理端 UI**（界面只放全局三档；`.env` 留能力级覆盖给部署场景）；
- 不引入 GRMR / 语法评价 / 任何新业务功能。

## 三、执行环境与全局约定

1. **本机开发验证（Windows）与部署目标（Linux x86_64 CPU，无 GPU）都必须能跑**。所有 Python 依赖只选有 Windows wheel + Linux wheel 的包。
2. 安装/运行命令一律 `env -u PYTHONPATH -u HTTP_PROXY -u HTTPS_PROXY`（WorkBuddy 会话注入的慢代理会坑死 dashscope 与大文件下载，已多次踩坑）。
3. pip 安装进 `backend/.venv`；国内镜像优先，镜像没有的包走官方 PyPI（`-i https://pypi.org/simple`）。
4. 后端接口约定：一律 `ok()`/`page()` envelope；**新接口只放 `app/api/xxx.py`**，禁止改 `main.py`（路由自动发现 `load_routers`）。
5. 管理端约定：请求只走 `admin-web/src/api/client.ts` 的 `api.get/post/put`；新页面配一个 `admin-web/src/router/routes/xxx.ts`（`import.meta.glob` 自动聚合，**不改 router/index.ts**）；菜单 order 不撞号（现役：content 10/20，server 50）。
6. requirements.txt **版本写死**（禁止 `^`/`~`/`>=`，`alibabacloud_ocr_api20210707>=2.0.0` 是历史遗留不改）：新包安装成功后，用 `pip show <pkg>` 取实测版本号写死。
7. 全量 pytest 前必须停掉 dev 后端（UDP 9527 互斥，否则 BE-08 假红）。
8. 模型文件放 `backend/models/`（该目录加进 `.gitignore`，不入库）；发布包不含模型，部署时用下载脚本或手动放置。
9. 删除被沙箱重定向回收站；vite 构建输出到全新 outDir。
10. 禁止在 `build()`/模块 import 期做重活；本地模型**懒加载**（首次请求时加载，进程内单例 + 锁）。
