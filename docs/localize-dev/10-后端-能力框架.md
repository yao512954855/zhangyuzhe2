## 4. ASR 顺序接入（改 `app/services/asr/session_manager.py`）

只改 `__init__` 建 router 的两行附近（~210-228 行），照契约 §1.3：

```python
self.raw = raw_config if raw_config is not None else load_asr_raw()
# localize-dev §1.3：按能力模式覆盖主备顺序（复制 dict，不改 load_asr_raw 原始返回）
asr_mode = resolve_mode("asr")
ordered = dict(self.raw)
if asr_mode == "cloud":
    ordered["provider"], ordered["backup_provider"] = "aliyun", ""
elif asr_mode == "hybrid":
    ordered["provider"], ordered["backup_provider"] = "local", "aliyun"
else:  # local
    ordered["provider"], ordered["backup_provider"] = "local", ""
self.router = router if router is not None else ASRRouter(ordered)
```

说明：本批次 `PROVIDERS` 里还没有 `"local"`，`ASRFactory.create("local")` 会抛 `ASRError`——这正是预期行为：ASRRouter 的既有语义会把建连失败落到下一顺位（hybrid→aliyun ✅），`local` 模式则明确报错（✅）。批次 E 注册 LocalProvider 后该错误自然消失。**不要**在本批次写任何假 local 实现。
