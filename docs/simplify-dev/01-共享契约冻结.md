## 2. 命名规范

- 表/列：`snake_case` 单数或既定复数（见 DDL）；JSON 字段与列名**同名**（不转驼峰）
- Python：模块/函数 `snake_case`；Dart/TS：`lowerCamelCase`（JSON 层除外）
- API 路径：`/api/<资源>[/<动作>]`，动词一律 `kebab-case` 后缀（如 `/api/dictation/grade`）
- 分页参数：`page`（1 起）、`page_size`（默认 20，上限 200）；响应 `total`

## 3. 数据库契约

### 3.1 新增 DDL（`003_simplify.sql` 全文冻结）

```sql
-- 003_simplify.sql：简化版数据模型。幂等：全部 DROP TABLE IF EXISTS + CREATE。
PRAGMA foreign_keys = ON;

CREATE TABLE book_units (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL,                     -- 如 Starter Unit 1
    sort        INTEGER NOT NULL DEFAULT 0,           -- 升序
    created_at  TEXT    NOT NULL
);

CREATE TABLE items (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id     INTEGER NOT NULL REFERENCES book_units(id) ON DELETE CASCADE,
    type        TEXT    NOT NULL CHECK (type IN ('word','phrase','sentence')),
    en          TEXT    NOT NULL,                     -- 英文（唯一性按 §3.3 软约束）
    pos         TEXT    NOT NULL DEFAULT '',          -- 词性，选填，如 adj. / v.
    zh          TEXT    NOT NULL,                     -- 中文释义
    alt_zh      TEXT    NOT NULL DEFAULT '',          -- 其他可接受答案，顿号「、」分隔
    sort        INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT    NOT NULL
);
CREATE INDEX idx_items_unit ON items(unit_id, type, sort);

CREATE TABLE wrong_book (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id        INTEGER NOT NULL REFERENCES items(id) ON DELETE CASCADE,
    mode           TEXT    NOT NULL CHECK (mode IN ('listen','spell_zh2en','spell_en2zh')),
    wrong_count    INTEGER NOT NULL DEFAULT 1,
    last_wrong_at  TEXT    NOT NULL,
    resolved_at    TEXT                                  -- 非空 = 已移出错题本
);
CREATE INDEX idx_wrong_open ON wrong_book(item_id, mode) WHERE resolved_at IS NULL;

CREATE TABLE practice_logs (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id      INTEGER NOT NULL,
    type         TEXT    NOT NULL CHECK (type IN ('word','phrase','sentence')),
    mode         TEXT    NOT NULL CHECK (mode IN ('listen','spell_zh2en','spell_en2zh')),
    total        INTEGER NOT NULL,                    -- 本次总题数
    correct      INTEGER NOT NULL,                    -- 正确个数
    wrong        INTEGER NOT NULL,                    -- 错误个数
    duration_ms  INTEGER NOT NULL,
    created_at   TEXT    NOT NULL
);
```

### 3.4 硬性数据约束

- `items.en` 非空去首尾空格；同 unit 同 type 下 `en` 重复 → 后端报 `20003`（软约束，DB 不加 UNIQUE，Excel 导入需要合并语义）
- `wrong_book` 同 `(item_id, mode)` 只允许一条未移出记录（`resolved_at IS NULL`）——由 wrongbook_service 用 UPSERT 保证，DB 不加唯一索引（SQLite 部分索引仅 WAL 生效，为可移植性放服务层）
- **`wrong_book` 状态三分（v1.3）**：未掌握（两列皆 NULL）/ 已掌握（`mastered_at` 非空且 `resolved_at` 空，判对时服务端自动写，**保留显示**）/ 已移出（`resolved_at` 非空，仅手动删除可到达）
- `book_units.parent_id`（v1.3）：只允许两级——`parent_id` 非空时其父行 `parent_id` 必须为空（服务层校验，DB 不加 CHECK）；删除一级 → 二级连同其 items 级联删（FK CASCADE）
- 所有 `created_at/…_at`：ISO8601 UTC 字符串（沿用现有 `utc_now_iso()`）

## 4. HTTP 契约

- **无鉴权**：全部接口不校验登录态（`Authorization` 头不存在）。已知取舍：局域网内任何设备可改内容，单家庭场景接受（写入设计文档，不处理）
- 响应统一 `ok()/page()` 现有信封：`{code, message, data}`，业务失败 = HTTP 200 + `code != 0`
- 错误码沿用 `core/errors.py` 现有常量；新增常量**只允许 WP-A 定义**：

| code | 含义 | 场景 |
|---|---|---|
| 20003 | 内容重复 | items.en 在同 unit+type 下重复 |
| 20004 | 无可练内容 | 单元下该 type 无条目 |
| 20005 | OCR 批改失败 | 云端 OCR 报错/超时（HTTP 侧仍 200） |
| 20006 | 图片无效 | 无法解码 / 超过 10MB / 格式不支持 |

- 图片上传：`multipart/form-data`，字段名 `file`，JPEG/PNG/WebP，≤10MB
- 分页接口列表：`GET /api/items`、`GET /api/wrongbook`、`GET /api/units`（units 返回全量树不分页）

## 5. WebSocket 契约（背链路拼读，复用现有通道；v1.3 交互重构）

- 端点与现有 ASR WS 相同（`asr_ws.py`），消息信封不变（`{type, ...}` / 音频二进制帧）。
- **v1.3 交互模型**（todo11 A5/A6 + 甲方原型图 2026-10-15）：**按住说话**（press-and-hold，
  仿微信语音），松开判定；语音屏/键盘屏**均无字母格**，统一「识别内容区」
  （判对=绿色+👍、判错=红色）；语音与键盘随时互切。

**App 上行**（每题一轮）：

| 消息 | 时机 | 语义 |
|---|---|---|
| `{type:'start', mode:'spell_zh2en', item_id, session_id}` | 按下大圆钮 | 开始本轮收音 |
| 音频二进制帧 | 按住期间 | 实时推流 |
| `{type:'end'}` | **松开** | 触发服务端整词判定 |

**服务端下行**：

| type | 载荷 | 语义 |
|---|---|---|
| `partial` | `{text, is_final:false, ts_ms}` | 按住中**实时回显**（决策 #11：识别字母实时上屏） |
| `utterance` | `{text, item_id, ts_ms}` | 语句级定版回显（Vosk 边界/静音收口），仅上屏 |
| `verdict` | `{correct:bool, text:str, session_id, item_id}` | **松开后整词判定结果**（新消息，替代 letter） |
| `error` | 现有 | abort/retry/keyboard |

- **`letter` 消息自 v1.3 废弃**：逐字母判格与字母格 UI 移除；
  `session_manager._on_utterance` 不再驱动判格，只透传回显。
- **判定口径（服务端唯一）**：整段转写经 `services/judge` 谐音映射还原为字母序列，
  与 `item.en` 字母序列（去空格/连字符）**完全一致 = 对**，否则 = 错；
  判错细节不逐格暴露（UI 只有红/绿）。判定引擎复用现有 `judge.py`（WP-F 保护）。
- **判错抑制**：verdict(correct=false) 下发后服务端忽略本轮后续音频帧；
  App 同时停推流。「再来一次」= 清空识别区 → 重新 start（不限次数）。
- **倒计时推进（决策 #5/#13）**：verdict 下发后 App 启动 N 秒倒计时
  （N=`settings.spell_verdict_countdown_s`，默认 3）——无操作自动切下一题
  （判对=正常推进；判错=判错留痕进错题本后推进）；点「再来一次」取消倒计时。
- **跳过**：任何时刻可点（原型图两屏均有）= 判错，`answer(correct=false)` 留痕
  + 错题本，立即下一题。
- **全场推进（决策 #14）**：「结束并结算」按钮移除；最后一题倒计时走完后
  App 自动 `POST /api/practice/settle`。
- 键盘屏判定走本地（§6.4），不经 WS。
- 断线重连沿用现有 ws_client 逻辑；断线转暂停态，不清作答进度。

### 6.4 学生端判定分工（v1.3 重写，替代「本地判格」）

- **语音（按住拼读）**：判定在**服务端**（§5 verdict）——ASR 有不确定性，
  判分口径服务端唯一；App 只消费 verdict 渲染绿/红与倒计时。
- **键盘（系统键盘优先，不可控回退自绘+调大字母间距，带 ⌫）**：学生逐字母
  拼进识别内容区（⌫ 逐格回退），填满后 App 本地等值比对（忽略大小写）→
  `POST /api/practice/answer`（correct 必填）。键盘输入无 ASR 误差，本地
  机械等值判断不属「判分」，不违反口径唯一原则。
- 两种方式随时互切（A6），互切不清空已填内容。
- 判对（answer correct=true）→ 服务端自动写 `mastered_at`；判错/跳过 →
  `POST /api/wrongbook/auto-add`（现有），**不再调 DELETE**（v1.1 #4 废除）。
