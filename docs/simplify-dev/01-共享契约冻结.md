**禁止**引入：ORM、大模型 SDK、除 flutter_tts 外的新音视频库、除 OCR SDK 外的新云 SDK。

## 2. 命名规范

- 表/列：`snake_case` 单数或既定复数（见 DDL）；JSON 字段与列名**同名**（不转驼峰）
- Python：模块/函数 `snake_case`；Dart/TS：`lowerCamelCase`（JSON 层除外）
- API 路径：`/api/<资源>[/<动作>]`，动词一律 `kebab-case` 后缀（如 `/api/dictation/grade`）
- 分页参数：`page`（1 起）、`page_size`（默认 20，上限 200）；响应 `total`

## 3. 数据库契约

### 3.1 新增 DDL（`003_simplify.sql` 全文冻结）

```sql
-- 003_simplify.sql：简化版数据模型。幂等：全部 DROP TABLE IF EXISTS + CREATE。
PRAGMA foreign_keys = ON;

CREATE TABLE book_units (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT    NOT NULL,                     -- 如 Starter Unit 1
    sort        INTEGER NOT NULL DEFAULT 0,           -- 升序
    created_at  TEXT    NOT NULL
);

CREATE TABLE items (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id     INTEGER NOT NULL REFERENCES book_units(id) ON DELETE CASCADE,
    type        TEXT    NOT NULL CHECK (type IN ('word','phrase','sentence')),
    en          TEXT    NOT NULL,                     -- 英文（唯一性按 §3.3 软约束）
    pos         TEXT    NOT NULL DEFAULT '',          -- 词性，选填，如 adj. / v.
    zh          TEXT    NOT NULL,                     -- 中文释义
    alt_zh      TEXT    NOT NULL DEFAULT '',          -- 其他可接受答案，顿号「、」分隔
    sort        INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT    NOT NULL
);
CREATE INDEX idx_items_unit ON items(unit_id, type, sort);

CREATE TABLE wrong_book (
    id             INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id        INTEGER NOT NULL REFERENCES items(id) ON DELETE CASCADE,
    mode           TEXT    NOT NULL CHECK (mode IN ('listen','spell_zh2en','spell_en2zh')),
    wrong_count    INTEGER NOT NULL DEFAULT 1,
    last_wrong_at  TEXT    NOT NULL,
    resolved_at    TEXT                                  -- 非空 = 已移出错题本
);
CREATE INDEX idx_wrong_open ON wrong_book(item_id, mode) WHERE resolved_at IS NULL;

CREATE TABLE practice_logs (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    unit_id      INTEGER NOT NULL,
    type         TEXT    NOT NULL CHECK (type IN ('word','phrase','sentence')),
    mode         TEXT    NOT NULL CHECK (mode IN ('listen','spell_zh2en','spell_en2zh')),
    total        INTEGER NOT NULL,                    -- 本次总题数
    correct      INTEGER NOT NULL,                    -- 正确个数
    wrong        INTEGER NOT NULL,                    -- 错误个数
    duration_ms  INTEGER NOT NULL,
    created_at   TEXT    NOT NULL
);
```

### 3.2 删除与保留（WP-F 执行，这里只定契约）

- **删表**：texts、words、homework、students、classes、content_versions、users、
  sessions、recitations、recitation_events 及其余旧业务表——以 `001/002` 全表清单
  对照，不在 §3.1 且不在保留清单的一律 `DROP`。
- **保留表**：`settings`（含 ASR 配置键）。
- **存量数据**：**不迁移**（姚工拍板：直接删除，重新录入）。因此
  草案中的 `scripts/migrate_legacy_words.py` **取消**。

### 3.3 写入方唯一性表（并发写冲突红线）

| 表 | 唯一写入包 | 其他包只读 |
|---|---|---|
| book_units / items | WP-A（后端接口层） | B（管理端）、C/D/E（App 经 API） |
| wrong_book | WP-A 的 wrongbook_service（C/D 经 `/api/wrongbook/auto-add` 间接写） | E |
| practice_logs | WP-A 的 practice_service（settle 时写） | I（验收统计） |

### 3.4 硬性数据约束

- `items.en` 非空去首尾空格；同 unit 同 type 下 `en` 重复 → 后端报 `20003`（软约束，DB 不加 UNIQUE，Excel 导入需要合并语义）
- `wrong_book` 同 `(item_id, mode)` 只允许一条未解决记录（`resolved_at IS NULL`）——由 wrongbook_service 用 UPSERT 保证，DB 不加唯一索引（SQLite 部分索引仅 WAL 生效，为可移植性放服务层）
- 所有 `created_at/…_at`：ISO8601 UTC 字符串（沿用现有 `utc_now_iso()`）

## 4. HTTP 契约

- **无鉴权**：全部接口不校验登录态（`Authorization` 头不存在）。已知取舍：局域网内任何设备可改内容，单家庭场景接受（写入设计文档，不处理）
- 响应统一 `ok()/page()` 现有信封：`{code, message, data}`，业务失败 = HTTP 200 + `code != 0`
- 错误码沿用 `core/errors.py` 现有常量；新增常量**只允许 WP-A 定义**：

| code | 含义 | 场景 |
|---|---|---|
| 20003 | 内容重复 | items.en 在同 unit+type 下重复 |
| 20004 | 无可练内容 | 单元下该 type 无条目 |
| 20005 | OCR 批改失败 | 云端 OCR 报错/超时（HTTP 侧仍 200） |
| 20006 | 图片无效 | 无法解码 / 超过 10MB / 格式不支持 |

- 图片上传：`multipart/form-data`，字段名 `file`，JPEG/PNG/WebP，≤10MB
- 分页接口列表：`GET /api/items`、`GET /api/wrongbook`、`GET /api/units`（units 返回全量树不分页）

### 4.1 接口清单（冻结）

```
# —— 单元与内容（WP-A 建，WP-B 用）——
GET    /api/units                     全量单元树 [{id,name,sort,counts:{word,phrase,sentence}}]
POST   /api/units                     {name,sort}
PUT    /api/units/{id}                {name?,sort?}
DELETE /api/units/{id}                级联删 items（DB ON DELETE CASCADE）
GET    /api/items?unit_id&type&page&page_size&keyword
POST   /api/items                     {unit_id,type,en,pos?,zh,alt_zh?,sort?}
PUT    /api/items/{id}                同上字段可选
DELETE /api/items/{id}
POST   /api/items/import              multipart: file(.xlsx) + form unit_id/type；返回 {inserted,duplicated,failed:[{row,reason}]}
GET    /api/items/export?unit_id&type → xlsx 二进制（列：英文|词性|中文|其他可接受答案）
GET    /api/items/import-template     → xlsx 二进制（表头+1 行示例）

# —— 练习（WP-A 建，C/D/E 用）——
POST   /api/practice/start            {unit_id,type,mode} → {session_id, items:[{id,en,pos,zh,alt_zh}]}（全量下发该组条目，组卷=全选）
POST   /api/practice/answer           {session_id,item_id,mode,answer,elapsed_ms} → {correct:bool, matched_zh?:str}
       # spell_en2zh 的「一致」判定走 compare_service（§6.1）；spell_zh2en 不走 HTTP——
       # 字母逐格判定在 App 本地完成（§6.2），此接口仅用于兜底校验与埋点（可选调用）
POST   /api/practice/settle           {session_id,duration_ms} → {}（服务端写 practice_logs）
POST   /api/wrongbook/auto-add        {item_id,mode} UPSERT 未解决记录（C/D 判错时调用）
GET    /api/wrongbook?group_by=unit|type&page&page_size
       → [{item_id,en,pos,zh,mode,wrong_count,last_wrong_at,unit_id,unit_name,type}]
DELETE /api/wrongbook/{item_id}/{mode}  手动移出（=置 resolved_at）

# —— 听写批改（WP-D 建，后端同步提供）——
POST   /api/dictation/grade           multipart: file(手写照片) + form words=["apple","banana",…]
       → {results:[{word,recognized,correct,confidence}], ocr_content}
       # recognized=与该词对齐上的 OCR 文本；无对齐则 recognized=""

# —— 系统保留（不变）——
GET /api/health、UDP 9527 发现应答、WS 见 §5
```

## 5. WebSocket 契约（背链路拼读，复用现有通道）

- 端点与现有 ASR WS 相同（`asr_ws.py`），消息信封不变（`{type, ...}` / 音频二进制帧）。
- **新增服务端下行消息**（WP-A 在 session_manager 加，WP-C 消费）：

| type | 载荷 | 语义 |
|---|---|---|
| `letter` | `{index:int, letter:str, correct:bool, session_id, item_id}` | 拼读流式判定：学生每说一个字母，服务端判当前格 |

- App 上行不变：音频帧 + `{type:'start', mode:'spell_zh2en', item_id}`、`{type:'end'}`。
- 判定引擎 = 现有 `services/judge.py` 拼读判定**原样复用**（签名见 §6.2），
  WP-F 不得删它；其单元测试文件同步保留。
- 断线重连沿用现有 ws_client 逻辑；断线时 App 转暂停态，不清作答进度。

### 6.4 学生端本地判格（WP-C 实现，不上服务端）

看中文背英文的逐字母方格：App 把 WS `letter` 消息与当前 item.en 的字母序列
（去空格与连字符）对位，`correct=true` 填格，填满即判对 → **立即切下一题**；
3 格连错给一次「用键盘点字母」入口（不扣分）。判定结果通过
`POST /api/practice/answer` 上报留痕（correct 必填）。

## 7. 枚举常量表（全局唯一取值）

| 枚举 | 取值 | 中文 | 语义 |
|---|---|---|---|
| item_type | `word` / `phrase` / `sentence` | 单词 / 词组 / 短句 | 内容类型；三端 UI、DB CHECK、API 校验统一用英文值 |
| practice_mode | `listen` | 听写 | 纸上写 + 拍照批改 |
| | `spell_zh2en` | 看中文背英文 | 逐字母拼读 |
| | `spell_en2zh` | 看英文背中文 | 说中文，别名表比对 |
| wrong 状态 | `resolved_at IS NULL` / 非空 | 未解决 / 已移出 | 布尔分层：DB 无布尔列，API 不暴露该字段，列表按 resolved_at 过滤 |

**禁止**出现第二套命名（如 `dictation`/`listen` 混用、`zh2en`/`spell_zh2en` 混用）。

## 9. 前端共享规范

- 管理端：请求只走 `api/client.ts`（WP-F 拆掉鉴权头逻辑后，B 不得再加回）；
  页面路由文件放 `router/routes/`；`ok()/page()` 信封解析复用 client 现状
- 学生端：`api_client.dart`/`ws_client.dart` 原样复用；主题 token、`AgeScope`
  适配沿用；**riverpod 3 无 valueOrNull（用 `asData?.value`）**；
  清栈一律 `pushNamedAndRemoveUntil`；异步按钮必须有 `_busy` + finally

## 10. 契约禁止清单（并发事故红线）
