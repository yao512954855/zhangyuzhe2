## WP-B 管理端两页（批次3，与 C/D 并行）

**目标**：菜单只剩三项——**分类**、**内容录入**、**服务地址**（服务地址页
WP-F 未删，原样保留，不在本包范围）。

### 文件

- `src/views/content/UnitList.vue`（分类页，重写 content 目录）
- `src/views/content/ItemTable.vue`（内容录入页）
- `src/components/UnitTree.vue`（两页共用的单元树组件）
- `src/api/units.ts`、`src/api/items.ts`
- `src/router/routes/content.ts`（重写，两个路由：`/units`、`/items`）

### 功能点

**分类页 UnitList**
1. 树/列表展示全部单元：名称、排序值、三类内容数量（数据来自 `GET /api/units` 的 `counts`）
2. 新建单元（name 必填、sort 默认 0）；编辑改名/排序；删除需确认弹窗，
   文案明确「将同时删除单元下全部单词/词组/短句」
3. 无学科/年级/学期任何选择器——这些概念已删除，**出现即缺陷**

**内容录入页 ItemTable**
4. 左侧 UnitTree 选单元，右侧按 `word/phrase/sentence` 三 tab 切换
5. 表格四列：英文 | 词性（选填）| 中文 | 其他可接受答案（选填，顿号分隔）；
   行内编辑（保存调 PUT）；顶部「新增一行」；删除行确认
6. `en` 在同单元同类型重复 → 前端先提示，后端 `20003` 兜底展示 message
7. Excel 批量导入：`POST /api/items/import`，结果弹窗展示
   inserted/duplicated/failed（失败行含 row+reason）
8. Excel 导出与模板下载按钮（走 `items/export`、`items/import-template`）
9. keyword 搜索框（走 `GET /api/items?keyword=`，前端不做本地过滤大列表）

### 共享规范（契约 §9）

- 请求只走 `api/client.ts`；页面不写裸 fetch
- `page()` 分页解析复用现有工具；空态用现有 EmptyState 风格

### 不做（Out of Scope）

- 不做学生/班级/作业/统计/版本任何页面或菜单残留
- 不做拖拽排序（sort 数字输入即可）
- 不动服务地址页与 `api/server.ts`

### 验收用例

| # | 用例 | 通过标准 |
|---|---|---|
| U1 | 菜单 | 仅 分类/内容录入/服务地址 三项，order 不撞号 |
| U2 | 新建单元 → 出现在树 | 刷新仍在；名称/sort 正确 |
| U3 | 删除有内容的单元 | 确认文案出现；删除后 items 计数归零（级联） |
| U4 | 录入一条 word：en/pos/zh/alt_zh | 列表回显一致；alt_zh 空可保存 |
| U5 | 重复 en 保存 | 前端提示 + 后端 20003 message 展示 |
| U6 | 行内编辑 zh → 保存 | 刷新后仍为新值 |
| U7 | 导入模板下载 | xlsx 可打开，含表头与示例行 |
| U8 | 导入含 2 重复 1 坏行的文件 | inserted/duplicated/failed 计数正确，失败行可读 |
| U9 | 导出 | 内容与库一致 |
| U10 | 三 tab 数据隔离 | word tab 看不到 phrase 条目 |
| U11 | 搜索 keyword | 服务端过滤生效 |
| U12 | `vue-tsc --noEmit` + `vite build` | 零 error |
| U13 | 页面入口 | 菜单可达（报告写明路径） |
