## WP-C 学生端背链路（批次3，与 B/D 并行）

**目标**：新首页 + 听背选单元页 + 背诵链路（两种模式 + 总结算自动回跳）。
同时独占 `lib/router/app_router.dart`——本批次所有路由注册由 C 收口（接力项 J1）。

### 文件

- `lib/features/home/`：清空重写——`home_page.dart`（两按钮：听背/错题本）、
  `unit_list_page.dart`（单元列表 + 类型单选）、`practice_entry.dart`（模式分发）
- `lib/features/recite/`：清空重写——`spell_config_page.dart`（看中文背英文/看英文背中文）、
  `spell_page.dart`（逐字母方格答题）、`settle_page.dart`（总结算）
- `lib/core/net/practice_ws.dart`：WS 会话封装（复用 `ws_client.dart`，
  新增 `letter` 消息解析）
- `lib/router/app_router.dart`、`lib/router/routes/{recite,home}.dart`
- `pubspec.yaml`（如需新增依赖）

### 功能点

1. **首页**：两个大按钮【听背】【错题本】；错题本按钮的跳转是接力项 J2
   （E 未交付前允许暂时置灰+提示「即将开放」——集成阶段销账）
2. **听背 → 单元列表**：`GET /api/units`；点单元 → 类型单选（○单词○词组○短句）
   → 底部【听】/【背】两按钮
3. **选【听】**：跳转 dictation 设置页——D 的页面；路由注册由 C 收口（J1），
   D 未交付前置灰
4. **选【背】**：`spell_config_page` 选模式 → `POST /api/practice/start`
   （mode=spell_zh2en / spell_en2zh）→ 进答题页
5. **看中文背英文（spell_zh2en）**：
   - 显示当前题中文（+词性）；下方与 `en` 字母数一致的方格（去空格连字符）
   - WS 连接、`start {mode:'spell_zh2en', item_id}` → 学生逐字母拼读 →
     消费 `letter {index, letter, correct}` → 正确填格；填满 =
     本题对 → `POST /api/practice/answer` 上报 → **立即切下一题**
   - 同一格 3 次 `correct=false` → 出现「用键盘点字母」入口（键盘填格
     不扣分，同样上报 correct）
   - 答错不中断：3 格连错也允许跳下一题（该题判错上报）
6. **看英文背中文（spell_en2zh）**：显示英文（+发音按钮，flutter_tts en-US）→
   学生说中文 → WS 语音转写 → `POST /api/practice/answer`
   （answer=转写文本，比对在服务端 compare_service）→ `correct=true`
   **立即切下一题**；false 显示「再试一次」不中断，学生可跳过（跳过=错）
7. **总结算**：全部题走完 → `POST /api/practice/settle` → 显示
   **正确 X · 错误 Y · 已记入错题 Z**（无分数无评级）；判错的题
   `POST /api/wrongbook/auto-add`（mode=对应模式）；停 3 秒自动
   `pushNamedAndRemoveUntil` 回单元列表（计时器 dispose 防泄漏）
8. 连接层沿用 UDP 发现/扫码/手输（bootstrap 未删部分），会话中断转暂停不清进度

## WP-E 错题本（批次4，C/D 页面就绪后）

**目标**：错题列表 + 按原模式重做 + 判对移出。

### 文件

- `lib/features/wrongbook/`：`wrongbook_page.dart`（分组列表）、
  `wrongbook_entry.dart`（重做组卷与分发）
- `lib/router/routes/wrongbook.dart`
- 路由注册与首页入口接线 = 接力项 J1/J2，**在报告里列明，不改 C 的文件**

### 功能点

1. `GET /api/wrongbook?group_by=unit` 分组展示：单元名 → 题目卡片
   （英文、中文、词性、mode 徽标、错误次数、最后错误时间）
2. 分页加载；手动「移出」（DELETE 接口）需确认
3. 「重做」：把选中（默认全部未解决）错题按各自 mode 分组，逐组走原链路：
   - `listen` → 跳 dictation（D 页面，J3 接线）
   - `spell_zh2en` / `spell_en2zh` → 跳背诵（C 页面，J3 接线）
   - 重做判对 → 该 (item_id, mode) 自动置 resolved：**约定由 C/D 在
     `answer correct=true` 后调 `DELETE /api/wrongbook/{item_id}/{mode}`**
     （判对移出是 C/D 链路的职责，E 只负责错题入口与展示；此约定同时写进
     C/D 的验收 U10/U7）
4. 重做结算沿用 C/D 的总结算页

### 验收用例

| # | 用例 | 通过标准 |
|---|---|---|
| U1 | 列表分组与徽标 | 三种 mode 徽标正确，错误次数递增显示 |
| U2 | 分页 | 翻页无重复无遗漏 |
| U3 | 手动移出 | 列表消失，DB resolved_at 非空（经 API 验证） |
| U4 | 重做入口按 mode 分发 | listen 错题进听写、spell 错题进背诵对应模式 |
| U5 | 重做判对移出 | 判对后回错题本该条消失 |
| U6 | 空错题本空态 | 无崩溃，文案友好 |
| U7 | analyze + 全量 test | 无新增问题、0 fail |
| U8 | 入口可达 | 首页错题本按钮 → 列表（J2 销账后验证） |
