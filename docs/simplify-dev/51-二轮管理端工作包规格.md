# 二轮·管理端工作包规格（todo11 / 契约 v1.3）

## WEB-11 单元树形管理 + 设置页

### 目标
管理端支持两级单元树形管理（B1）与设置页（听写/背诵倒计时、报词显示语言）。

### Out of Scope（不做）
- 后端任何文件（BE-11/12 已覆盖）
- 学生端任何页面
- items 录入/导入页的改造（现有一级单选逻辑保留可用；仅把单元选择器换成两级选择）

### 独占文件
```
admin-web/src/views/unit/UnitTree.vue         （新建；或改造现有 UnitList——以现有文件实际为准）
admin-web/src/views/server/SettingsPage.vue   （新建）
admin-web/src/api/units.ts                    （如拆分则新建；否则方法加进 api/client.ts）
admin-web/src/api/settings.ts                 （新建）
admin-web/src/router/routes/unit.ts           （路由文件，自动发现机制）
admin-web/src/router/routes/settings.ts       （新建）
```
⚠️ `api/client.ts` 为共享文件：本轮管理端只有本包，允许追加方法，但**不得改动既有方法签名**。

### 功能点
- **F14-1 树形展示**：两级树（展开/收起），每级显示 counts（一级为汇总值）；空态/加载态复用现有组件规范。
- **F14-2 增删改**：一级/二级新建（选父级）、改名、排序；删除有确认弹层（提示级联影响：一级删除将连带 N 个二级 + M 条内容）。
- **F14-3 移动归属**：二级可在一级之间移动（下拉选目标一级即可，不要求拖拽动画）；校验失败（挂到二级下）显示后端错误。
- **F14-4 设置页**：听写倒计时（1~10 秒数字输入）、背诵判定倒计时（1~10）、报词显示语言（zh/en 单选）；保存调 PUT /api/settings，成功反馈；非法值前端先拦 + 后端 10001 兜底展示。
- **F14-5 入口**：设置页挂在侧边栏（服务器设置同级）；单元树替换现有单元管理入口（旧页路由保留重定向，避免孤儿页）。

### 验收用例（节选）
- U14-1 建一级「三年级上册」→ 建二级「Unit 1」挂其下 → 树正确渲染、counts 正确
- U14-2 二级移动到另一一级 → 两边 counts 即时刷新
- U14-3 删除含 2 个二级、15 条内容的一级 → 确认文案数字正确 → 删除后树与 counts 正确
- U14-4 一级下直接建二级后再给二级建「三级」→ 入口不可见/请求被拒，无脏数据
- U14-5 设置页改倒计时 5 秒保存 → 刷新页面回读 5
- U14-6 倒计时输入 0 / 11 → 前端拦截提示；绕过直接 PUT → 展示后端 10001 文案
- U14-7 `vue-tsc --noEmit` 零 error；`npm run build` 零 error
- U14-8 所有新页面均有可达入口（侧边栏可见），无孤儿页
