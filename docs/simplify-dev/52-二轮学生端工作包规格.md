## APP-11 选单元：两级多选 + 类型多选

### 目标
选单元页两级树 + 多选单元（A1）、类型多选混听混背（A2），start 请求体数组化。

### Out of Scope
- 答题页交互（APP-12）、听写页与错题本页（APP-13）
- 后端组卷逻辑（BE-12；App 只按契约传参）

### 独占文件
```
student-app/lib/features/home/practice_entry.dart        （类型多选态）
student-app/lib/features/recite/spell_session.dart       （startSpellRun 请求体）
student-app/lib/features/config/practice_config_*.dart   （单元/类型选择页；实际路径以代码为准）
student-app/test/ 下对应新增/既有用例文件
```
⚠️ `practice_ws.dart` **不属于本包**（WS start 是每题级、不含单元参数，无需改）。

### 功能点
- **F15-1 两级列表**：一级分组可展开，二级单元带勾选框；一级行勾选 = 全选其下二级。
- **F15-2 多选规则**：≥1 个单元且所选类型在所选单元**合计有内容**才能开始；底部栏「已选 N 个单元 · 共 X 条」。
- **F15-3 类型多选**：单词/词组/短句 checkbox（默认全不选→至少选一个）；类型可用条数按所选单元求和。
- **F15-4 start 请求**：`{mode, unit_ids:[...], types:[...]}`（契约 §4.1）；错题本重做等单单元入口保留单数字段（回归不动）。
- **F15-5 听写入口**同样支持多单元多类型（listen 模式走同一选择页）。

### 验收用例（节选）
- U15-1 展开/收起、勾选联动（一级全选/取消）状态正确
- U15-2 跨一级分组勾选 2 个单元 → 底部栏计数与「共 X 条」按求和正确
- U15-3 所选单元下无所选类型内容 → 开始按钮禁用 + 提示
- U15-4 start 请求体断言：unit_ids/types 数组、顺序与勾选一致
- U15-5 只勾 1 个单元 → 请求体退化为数组单元素（契约允许，不发单数字段）
- U15-6 flutter analyze 零新增、全量 test 绿

## APP-12 背诵交互重构（本轮最大包）

### 目标
spell_zh2en 按契约 §5 v1.3 重构：按住说话、识别内容区（无字母格）、verdict 判定、
倒计时推进、再来一次/跳过、全自动结算（A5/A6 + 原型图）。

### Out of Scope
- 后端（BE-13）、选单元（APP-11）、听写/错题本页（APP-13）
- en2zh 模式交互（现有「开始说/我说完了」保留，仅随 verdict 改造被动适配——en2zh 不产生 verdict，不改）

### 独占文件
```
student-app/lib/features/recite/spell_page.dart
student-app/lib/core/net/practice_ws.dart
student-app/lib/core/audio/pcm_recorder.dart     （仅按住推流控制相关）
student-app/test/test_wpc_spell_test.dart
```

### 功能点
- **F16-1 按住说话**：底部大圆钮 press-and-hold——按下发 `start` 并开始推流；**松开发 `end`**；按住中识别内容区实时回显（partial/utterance，现有 utterances 流复用）。
- **F16-2 识别内容区**：替代字母格——按住中实时显示识别字母（浅色进行态）；verdict 后整段变绿+👍（对）或变红（错）。
- **F16-3 verdict 消费**：practice_ws 新增 `verdict` 流、**删除 letter 流与 LetterEvent**；page 收 verdict → 正确：上报 answer(correct=true) → 启动倒计时；错误：停推流、红色态。
- **F16-4 倒计时推进**：verdict 后启动 N 秒（N 从 `GET /api/settings` 的 `spell_verdict_countdown_s`，进入页面时拉取一次，拉取失败回退 3）——无操作自动下一题（对错均适用，错的先 auto-add）；「再来一次」清空识别区并取消倒计时，重新按住（不限次）。
- **F16-5 跳过**：两屏常驻按钮 = 判错（answer correct=false + auto-add）→ 立即下一题。
- **F16-6 键盘屏**：图标互切（麦克风⇄键盘，A6）；键盘 = 系统键盘优先（禁联想/自动纠错，`TextInputType` 定制；真机若弹中文输入法则回退自绘+调大间距——回退开关做成常量便于切换）；⌫ 逐字母回退；填满本地等值比对（忽略大小写）→ answer(correct 必填) → 同 F16-4 倒计时。
- **F16-7 全场推进**：「结束并结算」删除；最后一题倒计时走完自动 `POST /api/practice/settle`（unit_ids/types 传本轮快照）→ 结算页。
- **F16-8 错题联动**：判错/跳过 → auto-add（现有）；**删除「判对 DELETE wrongbook」逻辑**（v1.3 废除）。
- **F16-9 断线**：沿用暂停态不清进度；verdict 等待超时（1.5s）兜底：无 verdict 则按「本轮未判定」处理（可再来一次），不得卡死。

### 验收用例（节选，全部注入消息流可脚本化）
- U16-1 按住 → start 发出、音频推流；松开 → end 发出
- U16-2 按住中 partial/utterance 实时上屏（浅色）；松开收 verdict(correct=true) → 绿色+👍+倒计时启动
- U16-3 verdict(correct=false) → 红色、推流停止；此后到达的 partial 不再上屏
- U16-4 倒计时走完自动下一题（对/错两条路径）；「再来一次」取消倒计时并清空识别区
- U16-5 跳过 → answer(correct=false) + auto-add + 立即下一题
- U16-6 键盘屏：逐字母填入/⌫ 回退/填满自动判定上报；语音⇄键盘互切不清内容
- U16-7 最后一题倒计时走完 → settle 请求（unit_ids/types 快照）→ 结算页；无「结束并结算」按钮
- U16-8 全程无 letter 相关代码路径（grep 验证）+ analyze 零新增 + 全量 test 绿
- U16-9 verdict 超时兜底：end 后 1.5s 无 verdict → 可再来一次，页面不死锁

## APP-13 听写增强 + 错题本改造

### 目标
听写报词显示与倒计时（A3，**无 App 内作答**）；错题本三类 tab + 已掌握 + 批量删除（A7）。

### Out of Scope
- 背诵页（APP-12）、选单元（APP-11）、后端
- 拍照批改链路本身（A4 的结果页手动退出属本包；识别率优化后端侧不在本轮）

### 独占文件
```
student-app/lib/features/dictation/dictation_play_page.dart   （报词显示+倒计时）
student-app/lib/features/dictation/dictation_models.dart      （如需）
student-app/lib/features/dictation/dictation_result_page.dart （结果页手动退出按钮）
student-app/lib/features/ 下错题本页（实际路径以代码为准，eye_care 无关）
student-app/test/ 对应用例
```

### 功能点
- **F17-1 报词显示**：报词时屏幕显示该词的中文或英文（`settings.dictation_hint`，进听写时拉取；失败回退 zh）；显示位于报词动画区下方。
- **F17-2 倒计时**：报词后显示 N 秒倒计时（`dictation_countdown_s`，回退 3），到点自动报下一个词；学生未答完 = 漏（照常流转，不特判）。
- **F17-3 结果页手动退出**：批改完成展示结果页 + 「完成」按钮手动退出；移除自动退出。
- **F17-4 错题本三类 tab**：听写 / 看中背英 / 看英背中（mode 过滤，契约 §4.1）；每 tab 内按现有分组。
- **F17-5 已掌握**：`mastered_at` 非空显示「已掌握」小标记；status 默认 unmastered，可切换查看已掌握。
- **F17-6 批量删除**：多选模式勾选 → 批量移出（batch-resolve）→ 列表刷新；单条长按删除保留。

### 验收用例（节选）
- U17-1 dictation_hint=zh → 报「apple」时屏显「苹果」；=en → 屏显「apple」；拉取失败回退 zh 不炸
- U17-2 倒计时 N 秒到点自动报下一个词；报词序列不重不漏
- U17-3 结果页出现「完成」按钮，点击才退出；等待期间无自动跳转
- U17-4 三类 tab 切换 → 请求 mode 参数正确、列表各自独立
- U17-5 已掌握条目显示标记；切 status=mastered 只见已掌握
- U17-6 勾选 3 条批量移出 → resolved 计数=3、列表刷新、可切 all 验证仍在（仅标记）
- U17-7 analyze 零新增 + 全量 test 绿；听写回归用例（播报兜底 v1.2）不破坏
