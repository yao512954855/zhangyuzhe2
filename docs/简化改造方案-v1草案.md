## 0. 产品定位（改后）

- **一句话**：单用户、局域网、免登录的英语单词学习工具——内容只有**单词 / 词组 / 短句**，练习只有**听（听写）** 和**背（背诵）** 两种模式，配错题本。
- **部署形态不变**：Linux 一键包 / Windows 直跑，后端 8810，UDP 9527 发现，App 扫码/手输连接。
- **已知取舍**：全局无鉴权（管理端、学生端都不登录），局域网内任何设备可改内容、看记录——单家庭场景接受；日后若要落校多班级，鉴权层需加回。

## 1. 功能清单

### 1.1 管理端（web，无登录，两页 + 服务地址）

| 页面 | 内容 |
| --- | --- |
| 分类管理 | 树形：单元（Starter Unit 1/2/…）→ 固定三类「单词 / 词组 / 短句」。单元增删改、排序 |

### 1.2 学生端（App，免登录，连接方式不变）

```
启动（自动连服务）
 └─ 首页两个大按钮：【听背】【错题本】
     ├─【听背】→ 单元列表 → 选单元 + 选类型（○单词 ○词组 ○短句）
     │    ├─【听】听写：设置「报中文 / 报英文」+ 播报间隔（默认 10s，可调 5~30s）
     │    │      → 逐题连播（可重听当前题、可暂停；进度 10/36）
     │    │      → 学生在纸上写 → 播完/手动结束 → 拍照 → 云端 AI 批改
     │    │      → 结果页：对 X · 错 Y（逐题对错清单）；错题自动入错题本
     │    └─【背】背诵：设置「看中文背英文 / 看英文背中文」→ 开始
     │           ├─ 看中文背英文：显示中文 + 逐字母方格；学生逐字母拼读，
     │           │   语音识别对一个填一格；识别不准可切键盘点字母（兜底）
     │           ├─ 看英文背中文：显示英文；学生说中文，按「别名表+归一化」比对
     │           └─ 判对立刻切下一题（单词间不结算）；答错不中断，错题自动入本
     │           → 全部完成 → 总结算：正确 X · 错误 Y · 已记入错题 Z
     │           → 停 3 秒自动跳回单元列表（循环）
     └─【错题本】→ 按单元/类型分组的错题列表 → 重做（按错题原类型走原链路：
            中背英错→中背英重做；英背中错→英背中重做；听写错→听写重做）
            → 重做判对即移出错题本
```

**判分口径（全部按拍板执行）**
- 得分 = **正确个数**；结算只显示 正确 X / 错误 Y / 记入错题 Z。废 100 分制、扣分项、评级。
- 英背中「一致」判定：**别名表 + 归一化**——比对前剥词性前缀（adj. 等）、去标点、去「的/了/儿」尾缀；先精确匹配答案，再匹配「其他可接受答案」字段。不引入大模型实时比对（保住「判对秒切」节奏与离线能力；日后可做服务端可开关的增强）。
- 拼读逐字母识别：直接上现成 ASR 链路不做预研；不达标用键盘点字母兜底（键盘兜底不扣分，口径里没有扣分了）。
- 听写批改：**云端百炼多模态模型**（复用现有 key），识别手写英文 → 与答案比对（忽略大小写、连字符、空格）。

## 2. 数据库改动（新迁移文件 `002_simplify.sql`，不动 001）

**新增表**

```sql
book_units ( id, name, sort, created_at )              -- 单元（不再挂学科/年级/学期）
items      ( id, unit_id, type, en, pos, zh, alt_zh, sort, created_at )
           -- type: word | phrase | sentence
wrong_book ( id, item_id, mode, wrong_count, last_wrong_at, resolved_at )
           -- mode: listen | spell | zh2en；resolved_at 非空 = 已移出
practice_logs ( id, unit_id, type, mode, correct, wrong, duration_ms, created_at )
```

**删除表**：texts、words、recitations、recitation_events、homework、
students、classes、content_versions、users、sessions 等旧业务表。
settings / asr 配置相关保留。

**存量数据**：提供一次性迁移脚本 `scripts/migrate_legacy_words.py`，把现有
words 表英语词条 + units 搬进 `book_units`/`items`（词组/短句按现有分类对应）。
跑不跑由你定，默认发布包带空库。

## 6. 工作包与顺序（可并行拆分）

| 包 | 内容 | 依赖 |
| --- | --- | --- |
| WP-A 后端数据层 | 002 迁移 + units/items/wrongbook 接口 + 撤鉴权 | 无 |
| WP-B 管理端两页 | 分类树 + 速录表格 + Excel 导入导出 | A |
| WP-C 背链路 | 拼读填格 + 中文比对 + 新结算 | A |
| WP-D 听链路 | 连播播放器 + 拍照 + 百炼批改（含手写识别实测） | A |
| WP-E 错题本 | 表驱动重做链路 | C/D |
| WP-F 大清理 | 删语文/作业/大屏/版本/多用户/鉴权残留代码 | 最后做 |

顺序建议：A → B+C 并行 → D → E → F。**WP-D 的手写识别实测是全案最大风险点**，
做出最小闭环后第一时间拿真实手写样张验证识别率，不行尽早反馈甲方。

## 7. 已定决策记录（甲方/姚工拍板）

1. 拍照批改走云端，用现成百炼 key。
2. 得分口径 = 正确个数 / 错误个数，废 100 分制与评级。
3. 首页入口：「听背」+「错题本」。
4. 错题重做按错题原类型走原链路，判对移出。
5. 单字母拼读不做预研直接干，键盘兜底。
6. 英背中比对 = 别名表 + 归一化（不用大模型实时比对）。
7. 听写播完停 10 秒可调（5~30s），可重听可暂停。
8. Excel 批量导入保留。
9. 语文代码**删除**，不保留。
10. 全局无鉴权（管理端也不登录）。
11. 局域网连接（UDP 发现/扫码/手输）保留。
12. 结算停 3 秒自动回单元列表。
