# 背记系统 UI 设计规范（学生端）

| 项目 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 编制日期 | 2026-09-23 |
| 关联文档 | 《背记系统需求说明书》v0.2 |
| 适用端 | Flutter 学生端（手机 / 平板） |
| 核心诉求 | **护眼、美观、适合小初学生、零门槛** |

---

## 1. 设计原则

### 1.1 五条铁律

| 原则 | 含义 | 反例 |
|---|---|---|
| **不刺眼** | 任何界面都不出现纯白底 + 纯黑字的极端对比 | `#FFFFFF` 背景配 `#000000` 文字 |
| **不怕大** | 字号和触控目标按儿童标准放大，宁可占空间也不挤 | 14sp 正文、40dp 按钮 |
| **不打岔** | 答错不弹窗、不打断，用内联反馈让学生继续 | 错误时弹模态框要求点「确定」 |
| **不迷惑** | 一屏只做一件事，主操作永远在拇指区 | 一屏塞入设置、统计、练习三种功能 |
| **不催促** | 默认不限时，倒计时不做成压迫性的大红数字 | 全屏红色倒计时 + 滴答音效 |

### 1.2 分龄适配

同一个界面，按年级分三档调整密度与尺寸：

| 档位 | 年级 | 正文字号 | 课文显示字号 | 最小触控目标 | 单屏信息量 |
|---|---|---|---|---|---|
| 低年级 | 1–3 | 18sp | 36sp | **64 dp** | 极简，图标主导 |
| 中年级 | 4–6 | 17sp | 30sp | **56 dp** | 适中 |
| 高年级 | 7–9 | 16sp | 26sp | **48 dp** | 接近成人 |

- 档位由 `preferred_grade` 自动判定，学生可在设置中手动覆盖。
- **绝对下限：任何文字不小于 16sp，任何可点击元素不小于 48dp。** 这两条不允许为了「塞得下」而突破。

## 2. 色彩系统

### 2.1 主题一：日间 · 暖白（默认）

避免纯白刺眼，整体偏暖、低饱和。

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#F7F5F0` | 暖白，比纯白柔和 |
| 卡片背景 | `#FFFFFF` | 与背景形成轻微层次 |
| 主色 | `#2E7D74` | 青绿，平静专注，不亢奋 |
| 主色浅 | `#E3F0EE` | 选中态、标签底色 |
| 主色深 | `#1F5C55` | 按下态 |
| 文字 · 主 | `#2B2B2B` | 不用纯黑 |
| 文字 · 次 | `#6B6B6B` | |
| 文字 · 弱 | `#9A9A9A` | 占位、说明 |
| 分隔线 | `#E8E4DC` | 暖灰 |
| 正确 | `#4CAF7D` | 柔和绿，非荧光 |
| 正确浅 | `#E8F5EE` | |
| 错误 | `#E5645C` | 珊瑚红，非正红 |
| 错误浅 | `#FBEDEC` | |
| 提示 | `#E8A33D` | 暖黄 |
| 提示浅 | `#FCF3E4` | |

**对比度校验**：`#2B2B2B` on `#F7F5F0` ≈ 11.5:1。

> 目标区间为 **8:1 ~ 12:1**。低于 4.5:1 不达标（WCAG AA），高于 15:1 会明显刺眼，两端都要避开。

### 2.2 主题二：纸质护眼（可切换）

在日间基础上把背景换成米黄，进一步降低蓝光感，适合长时间阅读课文。

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F5EEDF` |
| 卡片背景 | `#FBF7ED` |
| 文字 · 主 | `#3A3428` |
| 其余 | 同日间主题 |

### 2.3 主题三：夜间

**不使用纯黑**（`#000000` 在发光屏上对比过强，反而更累眼），用深灰蓝。

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#1B1F23` | 深灰蓝，非纯黑 |
| 卡片背景 | `#24292E` | |
| 主色 | `#5CBDB0` | 提亮版主色 |
| 主色浅 | `#24352F` | |
| 文字 · 主 | `#D6D6D6` | **不用纯白**，避免夜间刺眼 |
| 文字 · 次 | `#9BA1A6` | |
| 分隔线 | `#32383E` | |
| 正确 | `#6FCF97` | |
| 错误 | `#F08A82` | |
| 提示 | `#F0BE6D` | |

### 2.4 主题切换策略

| 模式 | 规则 |
|---|---|
| 跟随系统 | 默认 |
| 手动指定 | 日间 / 纸质 / 夜间 |
| **自动暖色** | 开启后 19:00–07:00 自动切夜间，可关闭 |

切换入口放在「设置」页第一屏，**不埋在二级菜单**，因为这是高频且与健康相关的操作。

### 2.5 配色禁忌

| 禁止 | 原因 |
|---|---|
| 大面积高饱和纯色铺底 | 视觉疲劳，长时间注视不适 |
| 荧光色（`#00FF00` 类） | 刺眼 |
| 红绿同时大面积使用 | 色盲学生无法区分（必须配图标） |
| 闪烁 / 高频闪烁元素 | 光敏性癫痫风险，**绝对禁止** |
| 彩虹渐变、炫光、霓虹 | 分散注意力 |

## 3. 字体与排版

### 3.1 字体

| 语言 | 字体 | 说明 |
|---|---|---|
| 中文 | 系统默认（苹方 / 鸿蒙 Sans / 思源黑体） | 不额外打包，控制包体积 |
| 英文 · 单词 | Nunito 或 Quicksand（圆体） | 圆润字形对儿童更友好 |
| 数字 | 等宽数字（`tabular-nums`） | 计时、分数不跳动 |
| 课文正文 | 衬线体可选（思源宋体） | 长文阅读更舒适，需实测体积 |

### 3.2 字重

**只用 400（常规）和 500（中粗）两档。** 不使用 600 / 700 / 900——粗体在小字号下发闷，且中文粗体渲染质量参差。

### 3.3 字号与行高

| 场景 | 低年级 | 中年级 | 高年级 | 行高 |
|---|---|---|---|---|
| 页面标题 | 26sp | 24sp | 22sp | 1.4 |
| 卡片标题 | 20sp | 19sp | 18sp | 1.5 |
| 正文 | 18sp | 17sp | 16sp | 1.7 |
| 辅助说明 | 16sp | 16sp | 16sp | 1.6 |
| **课文背诵大字** | 36sp | 30sp | 26sp | 2.0 |
| 英文单词展示 | 40sp | 34sp | 30sp | 1.4 |
| 按钮文字 | 20sp | 18sp | 17sp | 1.0 |

**课文背诵行高必须 ≥ 2.0**：逐字点亮时字与字之间要有足够呼吸感，否则占位框和已点亮的字会糊成一片。

### 3.4 排版规范

- 单行文字长度：中文每行不超过 **20 字**，英文不超过 **40 字符**。
- 段落间距：正文段落之间 16dp。
- 对齐：正文左对齐，**不用两端对齐**（中文两端对齐会产生难看的字间距）。
- 不缩进：手机端不用首行缩进，用段间距区分段落。

## 4. 布局与触控

### 4.1 触控目标

| 元素 | 低年级 | 中年级 | 高年级 |
|---|---|---|---|
| 主按钮 | 64 dp 高 | 56 dp 高 | 52 dp 高 |
| 次级按钮 | 56 dp | 52 dp | 48 dp |
| 列表项 | 72 dp | 68 dp | 64 dp |
| 图标按钮 | 64 × 64 | 56 × 56 | 48 × 48 |

- 元素间距 ≥ **16 dp**，相邻按钮间距 ≥ **20 dp**（防误触）。
- **屏幕左右边缘 16 dp 内不放关键按钮**——防误触返回手势。
- 主操作按钮放在**屏幕下方 1/3 区域**，保证单手持机时拇指可及。

### 4.2 安全区

- 必须适配刘海屏（顶部安全区）与手势条（底部安全区）。
- 底部主按钮距手势条至少 16 dp。

### 4.3 横竖屏

- **竖屏为主**：手机场景。
- **横屏优化**：平板场景，尤其是语文背诵页——横屏一行能容下更多字，视线移动更少。
- 语文背诵页在横屏下增大课文区域占比，隐藏次要信息。

### 4.4 屏幕常亮

- **进入练习流程后保持屏幕常亮**。学生背课文时不会频繁触碰屏幕，息屏会打断节奏。
- 退出练习后恢复系统设置。

## 5. 动效与反馈

### 5.1 动效规范

| 项 | 规范 |
|---|---|
| 时长 | 200–300 ms（超过 400ms 显得拖沓） |
| 缓动 | `ease-out`（进入）、`ease-in`（退出） |
| 位移 | ≤ 24 dp，不做大幅飞入 |
| 缩放 | 0.96 → 1.0 |
| 禁用 | 旋转、翻转、弹跳、闪烁、粒子 |

- **严禁闪烁类动效**（频率 > 3 Hz 有光敏性癫痫风险，小学生尤其需要规避）。
- 提供「减少动效」开关，开启后仅保留淡入淡出（无障碍要求）。

### 5.2 状态反馈

**录音中**

- 必须有明显的视觉指示：呼吸圆（缓慢缩放）或实时波形。
- 必须配文字提示「正在听…」，不能只靠动画表达。
- 呼吸周期 ≥ 1.5 秒，不做快速跳动。

**答对**

- 视觉：柔和的正确色对勾 + 轻微放大。
- 触觉：`HapticFeedback.lightImpact`（约 50ms 短振动）。
- 音效：可选，上行短音（如 ding），音量适中。

**答错**

- 视觉：柔和的错误色 + 差异提示，**不用大红叉占满整屏**。
- 触觉：两下短振动（`lightImpact` × 2，间隔 100ms）。
- 音效：**不播放刺耳的下行音**。建议静默或极轻的提示音。
- **禁止使用模态弹窗**——答错后不打断，直接展示正确答案与差异，学生点「继续」翻页。

**加载中**

- 网络请求 < 1 秒：不显示任何加载指示（避免闪烁感）。
- 网络请求 ≥ 1 秒：显示骨架屏或进度指示。
- **不使用无限旋转的转圈图标**，改用进度条或骨架屏，让学生知道「大概还要多久」。

### 5.3 音效规范

| 场景 | 音效 | 音量 |
|---|---|---|
| 答对 | 短促上行音 | 中等 |
| 答错 | 极轻提示音或静默 | 低 |
| 完成一轮 | 温和的完成音 | 中等 |
| 休息提醒 | 柔和铃声 | 中等 |

- **全局音效开关**放在设置第一屏，默认开启。
- 严禁任何刺耳、惊悚、机械感强的音效。

## 6. 护眼专项

这一节是硬需求，不是可选项。

### 6.1 用眼休息提醒

- **每练习 20 分钟**（`eye_rest_minutes` 可配）弹出休息提醒页。
- 提醒页设计要求：
  - 全屏柔和背景（不刺眼），不用红色警告样式。
  - 文案温和：「已经练了 20 分钟啦，看看窗外休息一下吧」。
  - 提供 20 秒倒计时（对应 20-20-20 用眼法则），倒计时期间屏幕显示缓慢的呼吸圆。
  - 学生可点击「我休息好了」提前结束，**不强制锁定**（避免引发逆反）。
- 提醒间隔可配置，可在设置中关闭（但默认开启，且关闭时弹一次说明提示）。

### 6.2 自动暖色

- 19:00 至次日 07:00 自动切换夜间主题，降低蓝光感知。
- 可在设置中关闭自动切换，手动选主题。

### 6.3 亮度与对比

- 不主动修改系统亮度（干预系统设置是越权行为），但在首次启动的引导页提示学生调整到舒适亮度。
- 所有主题的对比度都控制在 8:1 ~ 12:1 区间，从设计上避免极端对比。

### 6.4 长时间使用的其他保护

| 措施 | 说明 |
|---|---|
| 屏幕常亮 | 练习中不息屏（已述 §4.4） |
| 语音长度提示 | 单次录音最长 30 秒自动结束，避免学生长时间对着麦克风 |
| 无压迫计时 | 默认不限时；开启限时时用**进度环**而非大红数字，且不做滴答音 |
| 坐姿提醒 | 可选，在休息提醒页附带「坐直一点哦」的温和提示 |

### 7.2 P1 服务器发现页

```
┌─────────────────────────────┐
│                             │
│         [ 系统图标 ]         │
│          背记系统            │
│                             │
│   ┌───────────────────┐     │
│   │   正在寻找服务器…   │     │
│   │   ● ● ●           │     │
│   └───────────────────┘     │
│                             │
│   ┌───────────────────┐     │
│   │   📷  扫码连接      │     │  ← 主按钮，最大
│   └───────────────────┘     │
│                             │
│   ┌───────────────────┐     │
│   │      手动输入地址   │     │  ← 次级
│   └───────────────────┘     │
│                             │
│   提示：请让老师给你看管理端  │
│   首页上的二维码            │
└─────────────────────────────┘
```

**要点**

- 启动即**静默尝试**上次成功的地址 + UDP 广播发现，全程不弹错误。
- 发现成功**自动进入**登录页，学生完全无感知。
- 只有发现失败才展示此页，且**主按钮是扫码**（不是手动输入）。
- 文案里不出现「IP」「端口」「网络」等术语。

### 7.3 P2 登录 / 注册页

```
┌─────────────────────────────┐
│         [ 系统图标 ]         │
│          背记系统            │
│                             │
│   ┌───────────────────┐     │
│   │  我的学号           │     │
│   └───────────────────┘     │
│   ┌───────────────────┐     │
│   │  我的密码           │     │
│   └───────────────────┘     │
│                             │
│   ┌───────────────────┐     │
│   │      登  录         │     │  ← 主按钮
│   └───────────────────┘     │
│                             │
│      第一次用？去注册 →      │
│                             │
└─────────────────────────────┘
```

**要点**

- 学号输入框唤起**数字键盘**（学号多为数字），但允许输入字母。
- 密码框提供「显示密码」的眼睛图标——小学生打错密码很常见，可见比隐藏更实用。
- 不用「用户名」这个词，用「我的学号」这类儿童能懂的说法。
- 注册页班级选择用**卡片列表**（不是下拉框），并允许「先不选」。

**状态图标设计**

| 状态 | 图形 | 颜色 |
|---|---|---|
| 未练 | 空心圆 | 文字弱色 |
| 练过 · 有错 | 圆内感叹号 | 错误色 |
| 练过 · 全对 | 圆内对勾 | 正确色 |
| 已掌握 | 实心星 | 提示色（暖黄） |

**要点**

- 每个单元卡片直接显示**数字型进度**（20/24 这种），学生一眼知道自己练到哪。
- 进度条用主色，不用红绿（红绿是股票习惯，学习场景用中性色更稳）。
- 「只练错题」做成常驻卡片，不用进二级页面。

**要点**

- 所有选项用**卡片 / 胶囊按钮**，绝不用下拉框。
- 选中态用主色浅底 + 主色描边 + 对勾，**不只靠颜色区分**。
- 顶部实时显示「本次 N 题 · 约 M 分钟」，让学生有心理预期。
- 单元页提供**「直接开始」**入口，跳过此页按默认配置开练。

### 7.6 P7 英语拼读页（含逐字母回显）

> **切分引导硬约束**：屏幕引导**必须逐字母**展示（`c ｜ l ｜ a ｜ s ｜ s`），**严禁显示音节切分**（`cla-ss`、`pen-cil`）。
> 实测依据：ASR 无法识别非词字母组合（`cla ss` → `Alex.`），22 条样本**无一正确**（`qa/ASR预研报告.md` §3.1）。
> 「轻轻念出每个字母」这句文案保留——它本身就是引导学生按字母念。

**听音中**

```
┌─────────────────────────────┐
│  第 3 / 20 题        ⏱ 不限时│
│                             │
│         教室                 │  ← 42sp 中文
│      classroom              │  ← 已答对部分，正向反馈
│                             │
│        ╭─────────╮          │
│        │  呼吸圆   │          │  ← 录音动效
│        ╰─────────╯          │
│        正在听…              │
│                             │
│      轻轻念出每个字母         │
│                             │
│   ┌───────────────────┐     │
│   │   我卡住了 / 提示    │     │
│   └───────────────────┘     │
│   ┌───────────────────┐     │
│   │   改用键盘          │     │  ← 常驻
│   └───────────────────┘     │
└─────────────────────────────┘
```

**判定后 · 差异回显（核心交互）**

```
┌─────────────────────────────┐
│  第 3 / 20 题                │
│                             │
│         教室                 │
│                             │
│   正确拼读                   │
│   c   l   a   s   s   r   o   o   m
│                             │
│   你拼读的                   │
│   c   l   e   s   s   r   o   o   m
│            ▲                │
│                             │
│   第 3 位听成了 e，应该是 a   │  ← 精确到位的反馈
│                             │
│   我听到的是：               │
│   see ell ee ess …          │  ← 原始识别文本
│                             │
│   ┌───────────────────┐     │
│   │   再试一次          │     │
│   └───────────────────┘     │
│   ┌───────────────────┐     │
│   │   我读对了           │     │  ← 申诉，仅 fuzzy/loose 出现
│   └───────────────────┘     │
└─────────────────────────────┘
```

**要点**

- 差异位用**图标 + 颜色双重标记**（不只靠颜色），并在下方用一句话说清「第几位、听成了什么、应该是什么」。
- 展示**原始识别文本**，让学生理解机器听到了什么，也减少「我明明念对了」的委屈感。
- 「再试一次」是主按钮，「我读对了」是次级按钮，视觉上明确主次。
- 回显**不自动消失**，由学生点「再试一次」或「继续」翻页——给学生充分的对照时间。

### 7.7 P8 语文背诵页

```
┌─────────────────────────────┐
│  ← 背影               ● 录制中│
│                             │
│  我与父亲不相见已二年余了，    │  ← 已背出的字，正常显示
│  我最不能忘记的是他的背影。    │
│                             │
│  那年冬天，祖母死了，        │  │
│  □□□□                    │  ← 当前位置空框
│                             │
│  （后面的字完全不显示）        │
│                             │
│                             │

│                             │
│   ┌───────────────────┐     │
│   │   我卡住了           │     │
│   └───────────────────┘     │
│   ┌───────────────────┐     │
│   │   结束背诵           │     │
│   └───────────────────┘     │
└─────────────────────────────┘
```

**要点**

- 已背出的字用**主色正常色**，未背出的**完全不显示**，当前位置用空框。
- 标点不显示，但保留换行与段落结构，让学生对文章形状有空间记忆。
- 顶部状态指示「录制中」，是**柔和的呼吸圆点**，不是闪烁的红点。
- 底部实时显示「已背 / 总字数」，给学生进度感，但**不显示倒计时**（除非开了限时）。
- 卡壳时自动降档提示，同时底部按钮轻微高亮，引导主动点击。

## 8. 组件规范

### 8.1 按钮

| 类型 | 高度 | 圆角 | 样式 |
|---|---|---|---|
| 主按钮 | 64 / 56 / 52 dp | 16 dp | 主色实底 + 主色深文字 / 白字 |
| 次按钮 | 56 / 52 / 48 dp | 16 dp | 主色描边 + 主色文字 + 透明底 |
| 文字按钮 | 48 dp | — | 主色文字 |
| 图标按钮 | 64 / 56 / 48 dp 方块 | 圆角 16 dp | 圆形浅底 + 图标 |

- 圆角统一 16 dp（比成人产品的 8 dp 更圆润，观感更亲和）。
- 按下态：缩放 0.96 + 底色加深，反馈必须即时。

### 8.2 卡片

- 圆角 20 dp，背景白色（夜间为深灰），**不用阴影**（阴影在高分辨率屏上显脏），用 1 dp 描边或背景色差区分层次。
- 内边距 20 dp。
- 卡片间距 16 dp。

### 8.3 进度展示

| 组件 | 规格 |
|---|---|
| 进度条 | 高 10 dp，圆角 5 dp，主色填充，底槽用浅灰 |
| 进度环 | 线宽 8 dp，用于限时场景 |
| 数字进度 | 「20/24」形式，数字等宽 |

**限时进度环**：顺时针缓慢消耗，颜色从主色渐变到提示色，**最后 10 秒才转为错误色**，且不闪动、不发声。

### 8.4 空状态

- 图形 + 一句话 + 一个行动按钮。
- 文案要正向，例如「这个单元还没练过呢，来试试吧」+「开始练习」。
- 不用「暂无数据」这类冷冰冰的文案。

## 9. 文案规范

### 9.1 语气

面向小初学生，**用他们能懂的话**，不用技术术语、不用指令式命令。

| 场景 | 错误写法 | 正确写法 |
|---|---|---|
| 识别失败 | ASR_ERROR_TIMEOUT | 没听清，再说一次好吗？ |
| 网络中断 | 网络连接异常 | 网络好像断了，先练这几题吧 |
| 找不到服务器 | 无法解析局域网地址 | 找不到服务器，让老师给你扫个码 |
| 答错 | 回答错误，判定为 WRONG | 这次差一点点，看看正确答案 |
| 限时到点 | 超时，自动提交 | 时间到啦，我们看下一题 |
| 使用键盘 | 切换至键盘输入模式 | 用键盘打出来吧 |

### 9.2 禁忌

- 不使用「错误」「失败」「不合格」这类评价性词汇作为标题。
- 不使用感叹号堆砌（「太棒了！！！🔥🔥🔥」）。
- 不出现「你」以外的称呼（不用「用户」「该生」）。
- 不出现技术术语：IP、端口、服务器、token、网络协议。

## 10. 无障碍

| 项 | 要求 |
|---|---|
| 字号缩放 | 全部使用 sp / 可缩放单位，不写死 px；支持系统字号放大 |
| 颜色独立 | 任何状态信息都**不能只靠颜色**表达，必须配图标或文字 |
| 对比度 | 正文 ≥ 4.5:1，大字号文字 ≥ 3:1 |
| 触控目标 | 最小 48 dp（本规范实际取 48–64 dp，优于标准） |
| 语义标签 | 所有图标按钮必须有 `semanticLabel`，供读屏识别 |
| 减少动效 | 支持系统「减少动态效果」设置，以及应用内开关 |
| 键盘可达 | 平板外接键盘时，所有交互可 Tab 到达 |

## 11. 性能与体验指标

| 指标 | 目标 |
|---|---|
| App 冷启动到可交互 | < 2 秒 |
| 页面切换 | < 200 ms，无白屏 |
| 题目渲染完成 | 题目出现即开始计时，渲染不得卡顿（直接关系计时准确性） |
| 逐字点亮响应 | partial 消息到达后 < 100 ms 内完成渲染 |
| 录音动效 | 恒定 60 fps，不掉帧 |
| 内存占用 | 稳定在 200 MB 以内（长时间背诵不外溢） |
| 包体积 | < 30 MB（不含字体资源） |
